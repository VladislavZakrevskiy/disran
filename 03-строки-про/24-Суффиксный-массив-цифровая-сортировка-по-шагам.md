# 24. Построение суффиксного массива цифровой сортировкой циклических строк

## 1. Что строим

Нужно построить суффиксный массив строки `S`.

Обычно добавляем терминатор:

```text
S = S + '$'
```

где `$` меньше всех остальных символов.

После этого сортировка суффиксов сводится к сортировке циклических сдвигов.

Почему?

Терминатор `$` уникальный и минимальный, поэтому каждый циклический сдвиг строки `S$` фактически соответствует одному суффиксу.

---

## 2. Главная идея алгоритма удвоения

Мы будем сортировать циклические сдвиги по первым:

```text
1, 2, 4, 8, 16, ...
```

символам.

На шаге `k` уже умеем сравнивать подстроки длины `2^k`.

Хотим получить порядок для длины:

```text
2^(k+1)
```

Подстрока длины `2^(k+1)` состоит из двух половин:

```text
первая половина длины 2^k
вторая половина длины 2^k
```

Значит, её можно описать парой классов:

```text
(c[i], c[i + 2^k])
```

где `c[x]` — класс эквивалентности подстроки длины `2^k`, начинающейся в `x`.

---

## 3. Что такое массивы `p` и `c`

`p` — порядок циклических сдвигов.

```text
p[i] = старт i-го сдвига в отсортированном порядке
```

`c` — классы эквивалентности.

```text
c[i] = номер класса подстроки, начинающейся в i
```

Если:

```text
c[i] < c[j]
```

то подстрока из `i` лексикографически меньше подстроки из `j` на текущей длине.

Если:

```text
c[i] == c[j]
```

то они пока равны на текущей длине.

---

## 4. Начальный шаг: сортируем по одному символу

Для строки:

```text
S = abab$
```

Индексы:

```text
0:a 1:b 2:a 3:b 4:$
```

Сортируем символы:

```text
$ < a < b
```

Порядок:

```text
p = [4, 0, 2, 1, 3]
```

Классы:

```text
c[4] = 0   ($)
c[0] = 1   (a)
c[2] = 1   (a)
c[1] = 2   (b)
c[3] = 2   (b)
```

То есть:

```text
c = [1, 2, 1, 2, 0]
```

---

## 5. Переход от длины `2^k` к `2^(k+1)`

На шаге `k = 0` длина половины:

```text
len = 1
```

Нужно отсортировать пары:

```text
(c[i], c[i + len])
```

Для `S = abab$`:

| i | cyclic substring length 2 | pair |
|---:|---|---|
| 0 | `ab` | `(1,2)` |
| 1 | `ba` | `(2,1)` |
| 2 | `ab` cyclic from 2 | `(1,2)` |
| 3 | `b$` | `(2,0)` |
| 4 | `$a` | `(0,1)` |

Сортировка пар даёт:

```text
p = [4, 0, 2, 3, 1]
```

Классы:

```text
c[4] = 0   ($a)
c[0] = 1   (ab)
c[2] = 1   (ab)
c[3] = 2   (b$)
c[1] = 3   (ba)
```

---

## 6. Почему используется цифровая сортировка

На каждом шаге нужно сортировать пары:

```text
(c[i], c[i + len])
```

Классы — это числа от `0` до `classes-1`.

Значит, пары можно сортировать counting sort / radix sort за линейное время.

Но есть ещё более хитрый трюк.

Если массив `p` уже отсортирован по второй половине, то для сортировки по паре достаточно:

1. сдвинуть все позиции `p[i]` назад на `len`;
2. отсортировать полученные позиции по первому классу `c[pos]` counting sort.

Почему?

Позиция:

```text
pos = p[i] - len
```

имеет вторую половину, начинающуюся в `p[i]`.

А `p` уже отсортирован по этим вторым половинам.

---

## 7. Один шаг алгоритма по коду

```cpp
for (int i = 0; i < n; i++) {
    pn[i] = p[i] - (1 << k);
    if (pn[i] < 0) pn[i] += n;
}

// counting sort по c[pn[i]]
```

После сортировки получаем новый `p`.

Потом пересчитываем классы:

```cpp
pair<int,int> cur = {c[p[i]], c[(p[i] + (1 << k)) % n]};
pair<int,int> prev = {c[p[i-1]], c[(p[i-1] + (1 << k)) % n]};

if (cur != prev) classes++;
cn[p[i]] = classes - 1;
```

---

## 8. Полный код построения

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> suffix_array(string s) {
    s += '$';
    int n = (int)s.size();

    vector<int> p(n), c(n);

    // k = 0: сортировка по одному символу
    vector<pair<char,int>> a(n);
    for (int i = 0; i < n; i++) {
        a[i] = {s[i], i};
    }
    sort(a.begin(), a.end());

    for (int i = 0; i < n; i++) {
        p[i] = a[i].second;
    }

    c[p[0]] = 0;
    for (int i = 1; i < n; i++) {
        if (a[i].first == a[i - 1].first) {
            c[p[i]] = c[p[i - 1]];
        } else {
            c[p[i]] = c[p[i - 1]] + 1;
        }
    }

    int k = 0;
    while ((1 << k) < n) {
        vector<int> pn(n), cn(n);

        for (int i = 0; i < n; i++) {
            pn[i] = p[i] - (1 << k);
            if (pn[i] < 0) pn[i] += n;
        }

        // counting sort по классу c[pn[i]]
        int classes = c[p[n - 1]] + 1;
        vector<int> cnt(classes, 0);
        for (int x : pn) cnt[c[x]]++;

        vector<int> pos(classes, 0);
        for (int i = 1; i < classes; i++) {
            pos[i] = pos[i - 1] + cnt[i - 1];
        }

        for (int x : pn) {
            int cl = c[x];
            p[pos[cl]] = x;
            pos[cl]++;
        }

        cn[p[0]] = 0;
        classes = 1;
        for (int i = 1; i < n; i++) {
            pair<int,int> cur = {
                c[p[i]],
                c[(p[i] + (1 << k)) % n]
            };
            pair<int,int> prev = {
                c[p[i - 1]],
                c[(p[i - 1] + (1 << k)) % n]
            };

            if (cur != prev) classes++;
            cn[p[i]] = classes - 1;
        }

        c.swap(cn);
        k++;
    }

    // Если нужен суффиксный массив исходной строки без суффикса '$',
    // обычно удаляют первый элемент p[0], потому что это позиция '$'.
    p.erase(p.begin());
    return p;
}
```

## 9. Пример до конца для `abab$`

После сортировки по символам:

```text
p = [4, 0, 2, 1, 3]
c = [1, 2, 1, 2, 0]
```

После сортировки по длине `2`:

```text
p = [4, 0, 2, 3, 1]
```

Суффиксы/циклические сдвиги по первым 2 символам:

```text
$a
ab
ab
b$
ba
```

После следующего шага длина `4`:

```text
p = [4, 2, 0, 3, 1]
```

Суффиксы:

```text
4: $
2: ab$
0: abab$
3: b$
1: bab$
```

Если убрать суффикс `$`, получаем суффиксный массив исходной строки `abab`:

```text
[2, 0, 3, 1]
```

## 10. Почему алгоритм корректен

Инвариант:

> После шага `k` массив `p` задаёт порядок циклических сдвигов по первым `2^k` символам, а `c` задаёт классы равных таких префиксов.

База:

```text
k = 0
```

Сортируем по одному символу, значит порядок по `2^0 = 1` символу правильный.

Переход:

Если знаем порядок по `2^k`, то строка длины `2^(k+1)` задаётся парой:

```text
(c[i], c[i + 2^k])
```

Сортировка этих пар даёт порядок по `2^(k+1)` символам.

Значит, инвариант сохраняется.

Когда:

```text
2^k >= n
```

мы отсортировали строки по длине не меньше всей строки, то есть получили полный порядок.

---

## 11. Сложность

Количество шагов:

```text
O(log n)
```

На каждом шаге counting sort работает за:

```text
O(n)
```

Итого:

```text
O(n log n)
```

Память:

```text
O(n)
```

## 12. Что сказать на зачёте

Короткий ответ:

> Для построения суффиксного массива добавляем уникальный минимальный символ `$` и сортируем циклические сдвиги строки. Алгоритм удвоения сначала сортирует сдвиги по одному символу, затем по `2`, `4`, `8` и так далее. На шаге `k` каждый сдвиг длины `2^(k+1)` описывается парой классов `(c[i], c[i+2^k])`. Эти пары сортируются цифровой сортировкой: позиции из уже отсортированного массива сдвигаются назад на `2^k`, затем сортируются counting sort по первому классу. После каждого шага пересчитываются классы. Всего `O(log n)` шагов по `O(n)`, значит время `O(n log n)`, память `O(n)`.
