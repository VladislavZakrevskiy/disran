# 22. Приложения суффиксного дерева

## 1. Главное свойство

Суффиксное дерево строки `S` содержит все суффиксы `S`.

Любая подстрока `S` является префиксом какого-то суффикса.

Значит:

> Чтобы найти подстроку `P` в `S`, нужно пройти `P` от корня по суффиксному дереву.

---

## 2. Поиск подстроки в строке

Построили суффиксное дерево для текста:

```text
S = banana$
```

Ищем:

```text
P = ana
```

Идём от корня по символам `a`, `n`, `a`.

Если путь существует, значит `P` есть в `S`.

Все листья в поддереве под точкой окончания пути дают позиции вхождений.

Для `banana`:

```text
ana встречается в позициях 1 и 3
```

Сложность:

```text
O(|P| + число_ответов)
```

---

## 3. Поиск набора подстрок

Есть один большой текст `S` и много запросов:

```text
P1, P2, ..., Pk
```

Делаем:

1. Строим суффиксное дерево для `S` один раз.
2. Для каждого `Pi` проходим по дереву.
3. Если путь есть — образец найден.
4. Если нужны все позиции — перечисляем листья под найденной точкой.

Сложность:

```text
Построение: O(|S|)
Запросы: O(sum |Pi| + суммарное число ответов)
```

---

## 4. Поиск в базе текстов

Пусть есть база документов:

```text
D1, D2, ..., Dk
```

Хотим быстро отвечать:

```text
в каких документах встречается образец P?
```

Строим обобщённое суффиксное дерево:

```text
D1#1D2#2...Dk#k
```

где `#1, #2, ...` — разные терминаторы.

Каждый лист помечаем номером документа.

Запрос `P`:

1. Идём по дереву по символам `P`.
2. Если путь отсутствует — `P` нигде не встречается.
3. Если путь есть — смотрим листья в поддереве и собираем номера документов.

Сложность:

```text
O(|P| + число найденных вхождений/документов)
```

---

## 5. Поиск набора образцов в одном тексте

Если есть много образцов и один текст, можно сделать двумя способами.

### Способ 1: суффиксное дерево текста

1. Строим дерево для текста.
2. Каждый образец ищем отдельно.

Хорошо, когда текст фиксирован, а запросов много.

### Способ 2: Ахо–Корасик

1. Строим автомат по образцам.
2. Один раз сканируем текст.

Хорошо, когда нужно найти сразу все образцы в одном проходе.

На зачёте полезно сказать:

```text
Суффиксное дерево удобно для фиксированного текста и многих запросов.
Ахо–Корасик удобен для фиксированного множества образцов и одного прохода по тексту.
```

## 6. Наибольшая общая подстрока двух строк

Даны:

```text
A = banana
B = ananas
```

Нужно найти самую длинную строку, которая встречается и в `A`, и в `B`.

Строим обобщённое суффиксное дерево:

```text
banana#ananas$
```

Листья от `A` красим в цвет `A`, листья от `B` — в цвет `B`.

Теперь нужно найти самую глубокую вершину, в поддереве которой есть оба цвета.

Глубина вершины = длина строки на пути от корня.

Самая глубокая такая вершина соответствует LCS.

Для примера:

```text
banana
ananas
```

Ответ:

```text
anana
```

---

## 7. LCS для большего числа строк

Для строк:

```text
S1, S2, ..., Sk
```

строим обобщённое дерево со своими терминаторами:

```text
S1#1S2#2...Sk#k
```

Каждый лист имеет цвет `i` — номер строки.

Для каждой вершины считаем множество цветов в её поддереве.

Нужна самая глубокая вершина, у которой есть все цвета:

```text
{1, 2, ..., k}
```

Если `k` большое, цвета можно хранить битсетами или счётчиками.

---

## 8. Статистика совпадений

Суффиксное дерево позволяет считать разные статистики.

### 8.1 Число вхождений подстроки

Ищем подстроку `P`.

Если путь найден, число вхождений равно числу листьев под найденной точкой.

Почему?

Каждый лист — один суффикс, а значит одна позиция начала.

### 8.2 Самая длинная повторяющаяся подстрока

Повторяющаяся подстрока встречается хотя бы два раза.

В суффиксном дереве это значит:

```text
у соответствующей вершины/точки в поддереве хотя бы два листа
```

Самая длинная повторяющаяся подстрока — это самая глубокая внутренняя вершина.

### 8.3 Число различных подстрок

Каждая различная подстрока соответствует некоторому пути, начинающемуся в корне.

Если ребро имеет длину `len`, то оно добавляет `len` новых подстрок.

Поэтому:

```text
число различных подстрок = сумма длин всех рёбер суффиксного дерева
```

Если строка без терминатора длины `n`, то также можно считать через суффиксный массив:

```text
n(n+1)/2 - sum(LCP)
```

## 9. Matching statistics

Для двух строк `A` и `B` иногда нужно для каждой позиции `i` в `B` найти длину наибольшего префикса `B[i..]`, который встречается в `A`.

Это называется статистикой совпадений.

Идея через суффиксное дерево:

1. Строим дерево для `A`.
2. Идём по символам `B`, стараясь продолжать путь.
3. Когда путь ломается, используем суффиксные ссылки, чтобы не начинать с нуля.

Так можно получить линейное время для всей строки `B`.

---

## 10. Сложности приложений

| Задача | Время после построения дерева |
|---|---:|
| Проверить, есть ли `P` в `S` | `O(|P|)` |
| Найти все позиции `P` | `O(|P| + occ)` |
| Найти набор запросов `P1..Pk` | `O(sum |Pi| + total_occ)` |
| LCS двух строк | `O(|A| + |B|)` после построения/обхода |
| LCS k строк | `O(total length)` плюс стоимость объединения цветов |
| Число различных подстрок | `O(n)` обход дерева |
| Самая длинная повторяющаяся подстрока | `O(n)` обход дерева |

---

## 11. Что сказать на зачёте

Короткий ответ:

> Суффиксное дерево позволяет искать подстроку `P` в тексте `S` за `O(|P|)`, потому что любая подстрока является префиксом некоторого суффикса. Все позиции вхождения получаются как листья под найденной точкой. Для набора запросов дерево строится один раз, затем каждый запрос ищется отдельно. Обобщённое суффиксное дерево строится для нескольких строк с разными терминаторами и используется для поиска в базе текстов и LCS: самая длинная общая подстрока соответствует самой глубокой вершине, в поддереве которой есть листья всех нужных цветов. Также дерево позволяет считать число вхождений подстроки, повторяющиеся подстроки и статистику совпадений.
