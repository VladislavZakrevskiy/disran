# Карманная сортировка

Источники: [Видео 1](https://www.youtube.com/watch?v=8D7AzV0Al8M). Ссылки на конкретные моменты сохранены в разделах.

В текстовых схемах: `✓` — совпадение или подтверждённый результат, `×` — несовпадение, `↑` — рассматриваемое место. Причина каждой отметки объясняется перед схемой.

## Карманная сортировка: распределение вместо большого общего сравнения

[Лекция 2, 1:12:49](https://www.youtube.com/watch?v=8D7AzV0Al8M&t=4369s)

Третью сортировку лектор разбирает обзорно. Заранее оговаривает: строгое доказательство времени через случайные величины и математическое ожидание здесь не даётся, поскольку соответствующий материал ещё не изучен.

Условия теперь другие: есть $n$ вещественных чисел из полуинтервала $[0,1)$, и они распределены равномерно. Интуиция равномерности в лекции: на промежутки одинаковой длины должно приходиться примерно одинаковое количество значений.

Разобьём весь полуинтервал на $n$ карманов:

$$
\left[0,\frac1n\right),\quad
\left[\frac1n,\frac2n\right),\quad\ldots,\quad
\left[\frac{n-1}{n},1\right).
$$

Распределим числа по карманам, отсортируем содержимое каждого простым алгоритмом, например вставками, затем выпишем карманы по порядку от первого к последнему.

Правильность склейки следует из границ карманов: любое число из более раннего кармана меньше любого числа из более позднего. Между карманами дополнительно сравнивать числа не нужно; внутри каждого порядок обеспечивает обычная сортировка.

### Как определить карман без поиска по всем интервалам

[Лекция 2, 1:20:41](https://www.youtube.com/watch?v=8D7AzV0Al8M&t=4841s)

Для числа $x\in[0,1)$ индекс кармана равен

$$
\lfloor nx\rfloor.
$$

### Маленький пример с одним неупорядоченным карманом

**Учебный пример:** числа или строки упрощены; вариант алгоритма сохранён.

Берём четыре числа `[0.7,0.1,0.6,0.3]` и четыре кармана. Например, `floor(4·0.7)=2`: число `0.7` попадёт в интервал `[0.5,0.75)`. Ниже виден каждый этап.

**Шаг 1. Выбираем четыре кармана.**

Разбиваем [0,1) на четыре одинаковых интервала. Индекс вычисляется как floor(4x): для 0.7 это 2, для 0.1 — 0, для 0.6 — 2, для 0.3 — 1. floor отбрасывает дробную часть; индекс 2 означает третий карман при счёте с нуля.

```text
x       0.7  0.1  0.6  0.3
⌊4x⌋     2    0    2    1
```

**Шаг 2. Раскладываем числа.**

Раскладываем числа, ничего пока не сортируя внутри. Поэтому в кармане 2 сначала лежит 0.7, затем 0.6 — в порядке прихода. Уже известно, что все числа кармана 0 меньше чисел кармана 1, а те меньше чисел кармана 2.

```text
[0,.25)     0.1
[.25,.5)    0.3
[.5,.75)    0.7  0.6
             ↑    ↑
[.75,1)      ∅
```

**Шаг 3. Сортируем внутри карманов.**

Единственный непустой карман с несколькими числами — карман 2. В нём 0.7>0.6, поэтому меняем их порядок. Карманы с одним числом уже отсортированы; пустой карман тоже не требует работы.

```text
Карман 2    0.6  0.7
             ✓    ✓
```

**Шаг 4. Читаем карманы от 0 до 3.**

Читаем содержимое карманов от меньшего индекса к большему. Внутри каждого порядок готов, а между карманами порядок обеспечивают непересекающиеся интервалы. Получаем [0.1,0.3,0.6,0.7].

```text
Ответ    0.1  0.3  0.6  0.7
          ✓    ✓    ✓    ✓
```

Лекционное объяснение алгоритма: [1:16:43–1:18:36](https://www.youtube.com/watch?v=8D7AzV0Al8M&t=4603s).

### Откуда берётся линейное время — и граница лекционного объяснения

[Лекция 2, 1:20:12](https://www.youtube.com/watch?v=8D7AzV0Al8M&t=4812s); [повтор, 1:28:37](https://www.youtube.com/watch?v=8D7AzV0Al8M&t=5317s)

Интуитивное рассуждение такое: если $n$ чисел равномерно разложены по $n$ карманам, в кармане ожидается мало элементов. Отсортировать один-два элемента можно за постоянное время. Карманов $n$, а при склейке суммарно просматриваем ровно $n$ элементов. Получается линейная суммарная работа.

Для понимания ограничения обозначим число элементов в кармане через $n_i$. При вставках работа имеет вид

$$
O\left(n+\sum_{i=0}^{n-1}n_i^2\right).
$$

Эта формула записывает словами объяснённые затраты: распределение и склейка плюс локальные сортировки. Маленькое среднее заполнение само по себе ещё не является доказательством линейной оценки этой суммы.

> [!important] Уточнение вероятностного смысла
> Равномерное случайное распределение не гарантирует ровно один элемент в каждом кармане и не исключает редкое скопление. В стандартной модели независимых равномерных чисел линейной является **ожидаемая** сложность, а не гарантированная сложность любого входа. В лекции дано объяснение этой идеи, но не доказательство математического ожидания; строгого вероятностного вывода здесь не приписываем лектору.

На вопрос о плохом входе лектор рассматривает случай, когда все $n$ чисел попали в один карман. Тогда его сортировка вставками требует $O(n^2)$ в худшем случае. Это показывает, почему предположение о распределении существенно и почему на произвольных данных линейную гарантию давать нельзя.

Карманная сортировка может использовать сравнения **внутри** карманов. Она выходит за модель исключительно сравнительной сортировки потому, что распределение по карманам использует числовое значение ключа и арифметику, а оценка времени опирается на дополнительные предпосылки о входе.
