## Глава 16. Основы бора

### 16.1 История и названия

В 1959 году **Рене де ла Бриандэ** и **Эдвард Фредкин** независимо предложили структуру данных для эффективного хранения и поиска строк. Фредкин назвал её **trie** — от слова re**trie**val (извлечение). Произносится как «трай» (хотя некоторые говорят «три»).

В русскоязычной традиции используют термин **бор** или **префиксное дерево**.

### 16.2 Мотивация

Допустим, у нас есть словарь из n строк, и мы хотим:
- Проверить, есть ли строка s в словаре
- Найти все строки с данным префиксом (автодополнение)
- Быстро вставлять и удалять строки

Какие варианты?

| Структура | Поиск строки s | Поиск по префиксу |
|-----------|---------------|-------------------|
| Отсортированный массив | O(\|s\| · log n) бинарный поиск | Неудобно |
| Хеш-таблица | O(\|s\|) в среднем | ❌ Невозможно |
| BST / AVL / КЧ | O(\|s\| · log n) | Неудобно |
| **Бор** | **O(\|s\|)** ✅ | **O(\|p\|)** ✅ |

Бор ищет строку за время, **пропорциональное длине строки**, а не количеству строк в словаре. Для коротких строк и большого словаря это огромное преимущество.

### 16.3 Определение

> **Бор (Trie)** — это корневое дерево, в котором:
> - Каждое **ребро** помечено одним **символом** из алфавита
> - Из любого узла выходит **не более одного** ребра с данным символом
> - **Путь** от корня до узла задаёт строку (конкатенация символов на рёбрах)
> - Некоторые узлы помечены как **терминальные** (конец слова)

### 16.4 Визуализация

Допустим, мы храним слова: `he`, `her`, `his`, `she`, `shy`

```
              (root)
             /      \
            h        s
           / \        \
          e   i        h
          |   |       / \
         *r   *s     e   y
          |          |
          *          *
```

Звёздочка `*` обозначает терминальный узел (конец слова).

Путь от корня:
- `h → e` = "he" ✓ (терминальный)
- `h → e → r` = "her" ✓ (терминальный)
- `h → i → s` = "his" ✓ (терминальный)
- `s → h → e` = "she" ✓ (терминальный)
- `s → h → y` = "shy" ✓ (терминальный)

А путь `h → i` = "hi" — **не** терминальный, такого слова в словаре нет.

### 16.5 Алфавит и его влияние

Размер алфавита **Σ** критически влияет на реализацию:

| Алфавит | \|Σ\| | Пример |
|---------|-------|--------|
| Строчные латинские | 26 | a–z |
| Латинские + цифры | 36 | a–z, 0–9 |
| ASCII | 128 | Все ASCII-символы |
| Unicode | ~150 000 | Всё на свете |
| Биты | 2 | 0, 1 (для чисел) |

Чем больше алфавит, тем больше памяти на каждый узел (если хранить массив ссылок на детей).

### 16.6 Структура узла

**Вариант 1: массив детей** (быстро, но много памяти)

```cpp
const int ALPHABET_SIZE = 26;  // строчные латинские буквы

struct Node {
    Node* children[ALPHABET_SIZE];
    bool isTerminal;            // конец слова?

    Node() : isTerminal(false) {
        for (int i = 0; i < ALPHABET_SIZE; i++)
            children[i] = nullptr;
    }
};
```

Доступ к ребёнку — O(1), но каждый узел занимает `26 × 8 = 208` байт (на 64-битной системе). Для миллиона узлов — ~200 МБ.

**Вариант 2: map / unordered_map** (экономно, но медленнее)

```cpp
struct Node {
    unordered_map<char, Node*> children;
    bool isTerminal;

    Node() : isTerminal(false) {}
};
```

Каждый узел хранит только существующие рёбра. Экономия памяти, но доступ к ребёнку — O(1) в среднем для unordered_map, O(log |Σ|) для map.

**Вариант 3: массив + компактное хранение** (для олимпиад)

```cpp
const int MAXN = 1000000;  // максимум узлов
const int ALPHABET = 26;

int children[MAXN][ALPHABET];  // children[v][c] = номер потомка
bool isTerminal[MAXN];
int sz = 1;  // следующий свободный индекс (0 — корень)

void init() {
    memset(children[0], -1, sizeof(children[0]));
    isTerminal[0] = false;
}

int newNode() {
    memset(children[sz], -1, sizeof(children[sz]));
    isTerminal[sz] = false;
    return sz++;
}
```

Быстро, предсказуемая память, удобно для контестов.

## Глава 17. Операции над бором

### 17.1 Вставка строки

Идём по строке символ за символом. Если ребра с нужным символом нет — создаём новый узел. В конце помечаем узел как терминальный.

```cpp
void insert(Node* root, const string& s) {
    Node* v = root;
    for (char c : s) {
        int idx = c - 'a';
        if (!v->children[idx]) {
            v->children[idx] = new Node();
        }
        v = v->children[idx];
    }
    v->isTerminal = true;
}
```

**Сложность:** O(|s|) — ровно один проход по строке.

**Пример:** вставляем "cat" в пустой бор

```
Шаг 0: (root)

Шаг 1: вставка 'c'
        (root)
          |
          c
          |
         ( )

Шаг 2: вставка 'a'
        (root)
          |
          c
          |
          a
          |
         ( )

Шаг 3: вставка 't', помечаем терминальным
        (root)
          |
          c
          |
          a
          |
         (t)*    ← терминальный
```

Теперь вставим "car":

```
        (root)
          |
          c
          |
          a
         / \
       (r)* (t)*
```

Путь `c → a` уже существовал — мы просто пошли по нему. Новый узел создан только для `r`.

### 17.2 Поиск строки

Идём по строке символ за символом. Если в какой-то момент нужного ребра нет — строки в боре нет. Если дошли до конца — проверяем флаг `isTerminal`.

```cpp
bool search(Node* root, const string& s) {
    Node* v = root;
    for (char c : s) {
        int idx = c - 'a';
        if (!v->children[idx]) {
            return false;  // такого пути нет
        }
        v = v->children[idx];
    }
    return v->isTerminal;  // дошли до конца — это слово?
}
```

**Сложность:** O(|s|).

**Важный момент:** если в боре есть "cat", то поиск "ca" вернёт `false` — путь есть, но узел не терминальный. Аналогично, поиск "cats" вернёт `false` — пути нет (нет ребра 's' из узла 't').

### 17.3 Поиск по префиксу

Проверяем, существует ли **хотя бы одна** строка с данным префиксом:

```cpp
bool hasPrefix(Node* root, const string& prefix) {
    Node* v = root;
    for (char c : prefix) {
        int idx = c - 'a';
        if (!v->children[idx]) {
            return false;
        }
        v = v->children[idx];
    }
    return true;  // путь существует — есть строки с этим префиксом
}
```

Отличие от `search`: не проверяем `isTerminal`. Если путь существует, значит, хотя бы одна строка (может, более длинная) проходит через этот узел.

### 17.4 Подсчёт слов с данным префиксом

Храним в каждом узле **счётчик** — сколько строк проходит через этот узел:

```cpp
struct Node {
    Node* children[26];
    bool isTerminal;
    int prefixCount;    // сколько строк проходит через этот узел

    Node() : isTerminal(false), prefixCount(0) {
        for (int i = 0; i < 26; i++)
            children[i] = nullptr;
    }
};

void insert(Node* root, const string& s) {
    Node* v = root;
    for (char c : s) {
        int idx = c - 'a';
        if (!v->children[idx])
            v->children[idx] = new Node();
        v = v->children[idx];
        v->prefixCount++;    // каждый узел на пути «видит» эту строку
    }
    v->isTerminal = true;
}

int countWithPrefix(Node* root, const string& prefix) {
    Node* v = root;
    for (char c : prefix) {
        int idx = c - 'a';
        if (!v->children[idx]) return 0;
        v = v->children[idx];
    }
    return v->prefixCount;
}
```

Теперь `countWithPrefix(root, "ca")` вернёт количество слов, начинающихся на "ca".

### 17.5 Удаление строки

Удаление сложнее: нужно убрать флаг `isTerminal`, а также удалить узлы, которые больше не нужны (не ведут ни к одному слову).

```cpp
bool erase(Node* v, const string& s, int depth) {
    if (!v) return false;

    if (depth == s.size()) {
        if (!v->isTerminal) return false;  // слова и не было
        v->isTerminal = false;

        // Если у узла нет детей — можно удалить
        for (int i = 0; i < 26; i++)
            if (v->children[i]) return false;  // есть дети — не удаляем
        return true;  // можно удалить этот узел
    }

    int idx = s[depth] - 'a';
    if (erase(v->children[idx], s, depth + 1)) {
        delete v->children[idx];
        v->children[idx] = nullptr;

        // Если текущий узел стал бесполезным — тоже удаляем
        if (!v->isTerminal) {
            for (int i = 0; i < 26; i++)
                if (v->children[i]) return false;
            return true;
        }
    }
    return false;
}

// Вызов: erase(root, "cat", 0);
```

**Сложность:** O(|s|).

### 17.6 Сбор всех слов (обход бора)

Полезно для автодополнения — собрать все слова с данным префиксом:

```cpp
void collect(Node* v, string& current, vector<string>& results) {
    if (!v) return;
    if (v->isTerminal) {
        results.push_back(current);
    }
    for (int c = 0; c < 26; c++) {
        if (v->children[c]) {
            current.push_back('a' + c);
            collect(v->children[c], current, results);
            current.pop_back();
        }
    }
}

vector<string> autocomplete(Node* root, const string& prefix) {
    Node* v = root;
    for (char c : prefix) {
        int idx = c - 'a';
        if (!v->children[idx]) return {};
        v = v->children[idx];
    }
    vector<string> results;
    string current = prefix;
    collect(v, current, results);
    return results;
}
```

## Глава 18. Сжатый бор (Patricia Trie / Radix Tree)

### 18.1 Проблема обычного бора

Рассмотрим бор со словами `algorithm`, `algorithmic`, `algorithms`:

```
a - l - g - o - r - i - t - h - m  ← "algorithm"
                                |
                                i - c  ← "algorithmic"
                                |
                                s  ← "algorithms"
```

Цепочка `a → l → g → o → r → i → t → h → m` — это **9 узлов**, каждый с единственным ребёнком. Мы тратим 9 узлов × 208 байт = ~1.8 КБ на хранение одного общего префикса.

Для реальных данных (URL, файловые пути, ДНК-последовательности) таких цепочек — подавляющее большинство узлов.

### 18.2 Идея сжатия

**Сжатый бор (Patricia trie)** объединяет цепочки узлов с одним ребёнком в **одно ребро**, помеченное **подстрокой**:

```
(root)
  |
"algorithm"
  |
 (*)  ← "algorithm" (терминальный)
 / \
"ic" "s"
 |    |
(*)  (*)  ← "algorithmic", "algorithms"
```

Вместо 11 узлов — **4 узла**. Драматическая экономия.

### 18.3 Формальное определение

> **Patricia trie (Radix tree)** — это сжатый бор, в котором:
> - Каждое ребро помечено **непустой подстрокой**
> - Каждый **внутренний** узел (кроме корня) имеет **≥ 2 детей**
> - Нет двух рёбер из одного узла, начинающихся на один и тот же символ

**Ключевое свойство:** для n строк Patricia trie содержит **O(n) узлов** (не зависит от длин строк!).

### 18.4 Сравнение визуально

Слова: `car`, `card`, `care`, `cat`

**Обычный бор** (8 узлов + корень):

```
        (root)
          |
          c
          |
          a
         / \
        r    t*
       / \
      d*   e*
```

Подождём... здесь `r` имеет 2 детей, так что не сожмётся. Но `c → a` — цепочка!

**Patricia trie** (6 узлов + корень):

```
        (root)
          |
        "ca"
        /   \
      "r"   "t"*
      / \
    "d"* "e"*
```

Ребро `"ca"` заменило два узла `c` и `a`.

### 18.5 Структура узла

```cpp
struct PatriciaNode {
    string edgeLabel;       // подстрока на ребре (от родителя к этому узлу)
    bool isTerminal;
    map<char, PatriciaNode*> children;  // ключ — первый символ ребра

    PatriciaNode(const string& label = "", bool terminal = false)
        : edgeLabel(label), isTerminal(terminal) {}
};
```

Заметь: ключ в `children` — это **первый символ** метки ребра. Поскольку из одного узла не выходит двух рёбер с одинаковым первым символом, это корректно.

## Глава 19. Операции над Patricia trie

### 19.1 Поиск

```
Ищем строку s, начиная с корня:
1. Смотрим на первый символ оставшейся части s
2. Находим ребро, начинающееся с этого символа
3. Сравниваем метку ребра с соответствующей частью s:
   - Если метка полностью совпадает → переходим к ребёнку, продолжаем
   - Если s закончилась внутри метки → строки нет (или нужно проверить)
   - Если несовпадение внутри метки → строки нет
4. Когда s полностью обработана — проверяем isTerminal
```

```cpp
bool search(PatriciaNode* root, const string& s) {
    PatriciaNode* v = root;
    int pos = 0;  // текущая позиция в строке s

    while (pos < s.size()) {
        char c = s[pos];
        if (v->children.find(c) == v->children.end()) {
            return false;  // нет ребра с таким символом
        }

        PatriciaNode* child = v->children[c];
        const string& label = child->edgeLabel;

        // Сравниваем метку ребра с соответствующим куском s
        int len = label.size();
        if (s.compare(pos, len, label) != 0) {
            // Метка не совпадает с s[pos..pos+len-1]
            return false;
        }

        pos += len;
        v = child;
    }

    return v->isTerminal;
}
```

**Сложность:** O(|s|) — каждый символ s сравнивается ровно один раз.

### 19.2 Вставка

Вставка сложнее, чем в обычном боре, потому что может потребоваться **разбиение ребра**:

```
Вставляем "car" в дерево, где уже есть "card":

До:    (root) → "card"* 

При вставке "car" мы идём по ребру "card" и обнаруживаем,
что "car" заканчивается ВНУТРИ ребра (после 'r', но до 'd').

Нужно разбить ребро:

После: (root) → "car"* → "d"*
```

Другой случай — расхождение:

```
Вставляем "cat" в дерево, где есть "car":

До:    (root) → "car"*

"cat" и "car" расходятся на 3-м символе ('t' vs 'r').
Нужно разбить ребро "car" на "ca" + "r" и добавить "t":

После: (root) → "ca" → "r"*
                      → "t"*
```

Полный алгоритм:

```cpp
void insert(PatriciaNode* root, const string& s) {
    PatriciaNode* v = root;
    int pos = 0;

    while (pos < s.size()) {
        char c = s[pos];

        if (v->children.find(c) == v->children.end()) {
            // Нет ребра — просто создаём новый лист
            PatriciaNode* leaf = new PatriciaNode(s.substr(pos), true);
            v->children[c] = leaf;
            return;
        }

        PatriciaNode* child = v->children[c];
        const string& label = child->edgeLabel;

        // Находим длину общего префикса label и s[pos..]
        int commonLen = 0;
        while (commonLen < label.size() &&
               pos + commonLen < s.size() &&
               label[commonLen] == s[pos + commonLen]) {
            commonLen++;
        }

        if (commonLen == label.size()) {
            // Метка полностью совпала — идём глубже
            pos += commonLen;
            v = child;
        } else {
            // Расхождение внутри метки — нужно разбить ребро
            //
            // Было:  v → [label] → child
            // Стало: v → [label[:commonLen]] → mid → [label[commonLen:]] → child
            //                                      → [s[pos+commonLen:]] → newLeaf

            PatriciaNode* mid = new PatriciaNode(label.substr(0, commonLen), false);

            // Старый ребёнок получает остаток метки
            child->edgeLabel = label.substr(commonLen);
            mid->children[child->edgeLabel[0]] = child;

            // Новый лист для вставляемой строки
            if (pos + commonLen < s.size()) {
                string remaining = s.substr(pos + commonLen);
                PatriciaNode* newLeaf = new PatriciaNode(remaining, true);
                mid->children[remaining[0]] = newLeaf;
            } else {
                // Вставляемая строка заканчивается ровно в точке разбиения
                mid->isTerminal = true;
            }

            v->children[c] = mid;
            return;
        }
    }

    // Строка закончилась в существующем узле
    v->isTerminal = true;
}
```

### 19.3 Пошаговый пример вставки

Вставляем последовательно: `car`, `card`, `care`, `cat`

```
Шаг 1: вставка "car"
    (root)
      |
    "car"*

Шаг 2: вставка "card"
    "car" и "card" — общий префикс "car" (3 символа)
    "car" совпал полностью → идём в узел "car"*
    Остаток "d" — создаём новое ребро

    (root)
      |
    "car"*
      |
     "d"*

Шаг 3: вставка "care"
    "car" совпал → идём в узел "car"*
    Остаток "e" — создаём новое ребро

    (root)
      |
    "car"*
     / \
   "d"* "e"*

Шаг 4: вставка "cat"
    Идём по ребру "car", но "cat" расходится на 3-м символе:
    "ca" — общий префикс, потом 'r' vs 't'
    Разбиваем ребро!

    (root)
      |
    "ca"           ← новый промежуточный узел
     / \
   "r"* "t"*       ← "r" забрал старых детей "d" и "e"
   / \
 "d"* "e"*
```

### 19.4 Удаление

При удалении, помимо снятия флага `isTerminal`, нужно **склеивать** узлы: если у внутреннего узла остался только один ребёнок, его нужно объединить с ребёнком (обратная операция к разбиению).

```cpp
bool erase(PatriciaNode* v, const string& s, int pos) {
    if (pos == s.size()) {
        if (!v->isTerminal) return false;
        v->isTerminal = false;
        return v->children.empty();  // можно ли удалить этот узел
    }

    char c = s[pos];
    if (v->children.find(c) == v->children.end()) return false;

    PatriciaNode* child = v->children[c];
    const string& label = child->edgeLabel;

    if (s.compare(pos, label.size(), label) != 0) return false;

    bool shouldDelete = erase(child, s, pos + label.size());

    if (shouldDelete) {
        delete child;
        v->children.erase(c);

        // Если v стал иметь одного ребёнка и не терминальный — склеиваем
        if (!v->isTerminal && v->children.size() == 1) {
            auto it = v->children.begin();
            PatriciaNode* onlyChild = it->second;
            v->edgeLabel += onlyChild->edgeLabel;
            v->isTerminal = onlyChild->isTerminal;
            v->children = onlyChild->children;
            delete onlyChild;
        }
    } else if (!child->isTerminal && child->children.size() == 1) {
        // Склеиваем child с его единственным ребёнком
        auto it = child->children.begin();
        PatriciaNode* grandchild = it->second;
        child->edgeLabel += grandchild->edgeLabel;
        child->isTerminal = grandchild->isTerminal;
        child->children = grandchild->children;
        delete grandchild;
    }

    return false;
}
```

## Глава 20. Применения и продвинутые темы

### 20.1 Автодополнение (Autocomplete)

Бор идеально подходит для автодополнения:

1. Пользователь вводит префикс "alg"
2. Спускаемся по бору до узла, соответствующего "alg"
3. Обходим поддерево этого узла, собирая все терминальные узлы
4. Возвращаем результаты: "algorithm", "algebra", "algae", ...

Для Patricia trie то же самое, но быстрее (меньше узлов).

### 20.2 Поиск по маске (с подстановочными символами)

Ищем слова, подходящие под маску, например `c?t` (где `?` — любой символ):

```cpp
void searchMask(Node* v, const string& mask, int pos,
                string& current, vector<string>& results) {
    if (pos == mask.size()) {
        if (v->isTerminal) results.push_back(current);
        return;
    }

    if (mask[pos] == '?') {
        // Перебираем все возможные символы
        for (int c = 0; c < 26; c++) {
            if (v->children[c]) {
                current.push_back('a' + c);
                searchMask(v->children[c], mask, pos + 1, current, results);
                current.pop_back();
            }
        }
    } else {
        int idx = mask[pos] - 'a';
        if (v->children[idx]) {
            current.push_back(mask[pos]);
            searchMask(v->children[idx], mask, pos + 1, current, results);
            current.pop_back();
        }
    }
}
```

### 20.3 IP-маршрутизация (Longest Prefix Match)

Маршрутизаторы хранят таблицу маршрутов вида:

```
192.168.0.0/16  → интерфейс A
192.168.1.0/24  → интерфейс B
10.0.0.0/8      → интерфейс C
```

Для пакета с адресом `192.168.1.42` нужно найти **наиболее длинный совпадающий префикс**. Patricia trie на битах — стандартное решение.

### 20.4 Бор на битах (Bitwise Trie)

Для работы с числами используют бор, где алфавит = {0, 1}, а «строка» — это двоичное представление числа (от старшего бита к младшему).

Классическая задача: **найти пару чисел в массиве с максимальным XOR**.

```cpp
// Вставка числа (30 бит)
void insert(Node* root, int num) {
    Node* v = root;
    for (int i = 29; i >= 0; i--) {
        int bit = (num >> i) & 1;
        if (!v->children[bit])
            v->children[bit] = new Node();
        v = v->children[bit];
    }
}

// Найти число в боре, дающее максимальный XOR с num
int maxXor(Node* root, int num) {
    Node* v = root;
    int result = 0;
    for (int i = 29; i >= 0; i--) {
        int bit = (num >> i) & 1;
        int want = 1 - bit;  // хотим противоположный бит
        if (v->children[want]) {
            result |= (1 << i);
            v = v->children[want];
        } else {
            v = v->children[bit];
        }
    }
    return result;
}
```

### 20.5 Сравнение подходов к хранению строк

| Критерий          | Хеш-таблица      | BST (строковый) | Бор              | Patricia trie |
| ----------------- | ---------------- | --------------- | ---------------- | ------------- |
| Поиск             | O(\|s\|) среднее | O(\|s\|·log n)  | O(\|s\|)         | O(\|s\|)      |
| Поиск по префиксу | ❌                | Сложно          | ⭐ O(\|p\|)       | ⭐ O(\|p\|)    |
| Память            | Хорошо           | Хорошо          | **Плохо**        | **Хорошо**    |
| Узлов             | O(n)             | O(n)            | O(сумма \|s\|)   | **O(n)**      |
| Порядок обхода    | ❌                | ✅               | ✅ (лексикограф.) | ✅             |

### 20.6 Полная реализация бора на C++ (контестный стиль)

```cpp
#include <iostream>
#include <cstring>
#include <vector>
#include <string>
using namespace std;

const int MAXN = 500000;
const int ALPHA = 26;

int ch[MAXN][ALPHA];  // дети
bool term[MAXN];       // терминальный?
int cnt[MAXN];         // число строк через узел
int sz;

void init() {
    sz = 1;
    memset(ch[0], -1, sizeof(ch[0]));
    term[0] = false;
    cnt[0] = 0;
}

void insert(const string& s) {
    int v = 0;
    for (char c : s) {
        int id = c - 'a';
        if (ch[v][id] == -1) {
            memset(ch[sz], -1, sizeof(ch[sz]));
            term[sz] = false;
            cnt[sz] = 0;
            ch[v][id] = sz++;
        }
        v = ch[v][id];
        cnt[v]++;
    }
    term[v] = true;
}

bool search(const string& s) {
    int v = 0;
    for (char c : s) {
        int id = c - 'a';
        if (ch[v][id] == -1) return false;
        v = ch[v][id];
    }
    return term[v];
}

int countPrefix(const string& p) {
    int v = 0;
    for (char c : p) {
        int id = c - 'a';
        if (ch[v][id] == -1) return 0;
        v = ch[v][id];
    }
    return cnt[v];
}

// Сбор всех слов с данным префиксом
void collect(int v, string& cur, vector<string>& res) {
    if (term[v]) res.push_back(cur);
    for (int c = 0; c < ALPHA; c++) {
        if (ch[v][c] != -1) {
            cur.push_back('a' + c);
            collect(ch[v][c], cur, res);
            cur.pop_back();
        }
    }
}

vector<string> autocomplete(const string& prefix) {
    int v = 0;
    for (char c : prefix) {
        int id = c - 'a';
        if (ch[v][id] == -1) return {};
        v = ch[v][id];
    }
    vector<string> res;
    string cur = prefix;
    collect(v, cur, res);
    return res;
}

int main() {
    init();

    insert("car");
    insert("card");
    insert("care");
    insert("cat");
    insert("dog");

    cout << "search 'car': " << search("car") << endl;   // 1
    cout << "search 'ca': " << search("ca") << endl;     // 0
    cout << "prefix 'ca': " << countPrefix("ca") << endl; // 4
    cout << "prefix 'car': " << countPrefix("car") << endl; // 3

    cout << "autocomplete 'ca':";
    for (auto& s : autocomplete("ca")) cout << " " << s;
    cout << endl;  // car card care cat

    return 0;
}
```
