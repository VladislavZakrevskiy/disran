# 1. AVL-дерево — как рассказывать

Начать можно так:

> AVL-дерево — это бинарное дерево поиска, в котором для каждой вершины высоты левого и правого поддеревьев отличаются не более чем на 1.

Вводим баланс:

\[ BF(v)=h(left)-h(right) \]

Для корректного AVL:

\[ BF(v)\in\{-1,0,1\} \]

Если после вставки или удаления получилось `+2` или `-2`, дерево нужно балансировать поворотами.

---

## Вставка в AVL

Говоришь:

> Сначала вставляем вершину как в обычное BST. После этого идём от вставленной вершины вверх, пересчитываем высоты и ищем первую разбалансированную вершину.

Пусть это вершина `A`.

Дальше всего **4 случая**.

---

## LL — левый-левый

Ситуация:

```
        A
       /
      B
     /
    C
```

У `A` слишком тяжёлое левое поддерево:

\[ BF(A)=+2 \]

И у `B` перевес тоже влево.

Что говоришь:

> Мы ушли от A влево, а потом ещё раз влево. Получился случай LL. Исправляется одним правым поворотом вокруг A.

```
        A                   B
       /                   / \
      B        →          C   A
     /
    C
```

### Запомнить

**LL → Right Rotate**

Потому что дерево завалилось влево — крутим вправо.

---

# RR — правый-правый

```
    A
     \
      B
       \
        C
```

\[ BF(A)=-2 \]

Что говоришь:

> От A мы пошли вправо и ещё раз вправо. Это RR. Выполняем один левый поворот вокруг A.

```
    A                       B
     \                     / \
      B        →          A   C
       \
        C
```

### Запомнить

**RR → Left Rotate**

---

# LR — левый-правый

```
        A
       /
      B
       \
        C
```

Это уже "зигзаг".

Что говоришь:

> A перегружена слева, но её левый сын B перегружен справа. Одним поворотом ситуацию не исправить. Сначала превращаем LR в LL левым поворотом вокруг B, затем выполняем правый поворот вокруг A.

Шаг 1:

```
        A
       /
      B
       \
        C
```

Левый поворот `B`:

```
        A
       /
      C
     /
    B
```

Теперь LL.

Правый поворот `A`:

```
        C
       / \
      B   A
```

### Формула

**LR:**

1. `rotateLeft(B)`
2. `rotateRight(A)`

---

# RL — правый-левый

Симметрично:

```
    A
     \
      B
     /
    C
```

Что говоришь:

> A перегружена справа, но правый сын B перегружен слева. Это RL. Сначала делаем правый поворот вокруг B, получаем RR, затем левый поворот вокруг A.

```
    A
     \
      B
     /
    C
```

↓

```
    A
     \
      C
       \
        B
```

↓

```
        C
       / \
      A   B
```

### Формула

**RL:**

1. `rotateRight(B)`
2. `rotateLeft(A)`

---

# Как не путать 4 случая AVL

Смотри на путь от сломанной вершины:

```
LL → право
RR → лево

LR → лево у сына, потом право у родителя
RL → право у сына, потом лево у родителя
```

Или ещё проще:

```
прямая линия → 1 поворот
зигзаг       → 2 поворота
```

---

# Удаление из AVL

Здесь на защите можно сказать:

> Удаление сначала происходит как в обычном BST. Если у вершины два ребёнка, заменяем её на следующий или предыдущий по порядку элемент и фактически удаляем вершину с нулём или одним ребёнком. После этого идём вверх к корню, пересчитываем высоты и восстанавливаем баланс.

Те же четыре геометрических случая:

```
BF(A) = +2
    BF(left) >= 0 → LL
    BF(left) <  0 → LR

BF(A) = -2
    BF(right) <= 0 → RR
    BF(right) >  0 → RL
```

Обрати внимание: **при удалении у ребёнка баланс может быть 0**.

Например:

```
BF(A) = +2
BF(B) = 0
```

тоже достаточно одного правого поворота.

---

# Почему AVL остаётся быстрым

> Благодаря ограничению на разницу высот дерево не может превратиться в список. Его высота всегда O(log n), поэтому поиск, вставка и удаление работают за O(log n).

Поворот сам по себе:

\[ O(1) \]

Но пройти от вершины до корня:

\[ O(\log n) \]

---

# Готовый рассказ AVL на защите

Можно почти дословно:

> AVL — это сбалансированное бинарное дерево поиска. Для каждой вершины разница высот левого и правого поддерева не превышает единицу. Обычно вводится balance factor: высота левого минус высота правого поддерева. Он должен быть -1, 0 или 1.
> 
> Вставку сначала выполняем как в обычном BST, после чего поднимаемся вверх и пересчитываем высоты. Если получаем баланс плюс или минус 2, выполняем повороты.
> 
> Есть четыре случая. LL — левый сын и его левое поддерево, выполняется один правый поворот. RR симметричен — один левый поворот. LR — сначала левый поворот вокруг левого сына, затем правый вокруг вершины. RL — сначала правый поворот вокруг правого сына, затем левый вокруг вершины.
> 
> При удалении сначала удаляем как в BST, а затем также поднимаемся к корню и балансируем. В отличие от вставки, после удаления может потребоваться несколько балансировок по пути к корню.
> 
> Так как высота AVL-дерева O(log n), поиск, вставка и удаление работают за O(log n).

Этого уже очень хорошо для AVL.
