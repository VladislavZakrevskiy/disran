## Глава 21. Мотивация: деревья для дисков

### 21.1 Проблема: оперативная память vs диск

Все деревья, которые мы изучали ранее (AVL, красно-чёрное, treap, бор), предполагают, что данные находят ся в **оперативной памяти**. Доступ к любому узлу — наносекунды.

Но что если данных **больше, чем помещается в RAM**? Например:
- База данных с миллиардами записей
- Файловая система с миллионами файлов
- Индекс поисковой системы

Данные хранятся на **диске** (HDD или SSD). И тут возникает критическая разница:

| Операция | RAM | HDD | SSD |
|----------|-----|-----|-----|
| Случайное чтение | ~100 нс | ~10 мс | ~100 мкс |
| Разница с RAM | 1× | **100 000×** | **1000×** |

Одно обращение к диску в **сто тысяч раз** медленнее, чем к RAM. Это значит, что **количество дисковых чтений** — главная метрика эффективности.

### 21.2 Почему AVL и красно-чёрные деревья плохи для диска

AVL-дерево с n = 10⁹ (миллиард записей) имеет высоту:

```
h ≈ 1.44 · log₂(10⁹) ≈ 1.44 · 30 ≈ 43
```

Каждый поиск — **43 обращения к диску**. При 10 мс на обращение — **0.43 секунды** на один запрос. Для базы данных это катастрофа.

Проблема в том, что бинарные деревья — **слишком тонкие**. Каждый узел хранит один ключ, а мы тратим целое дисковое чтение на получение одного ключа.

### 21.3 Ключевая идея: толстые узлы

Диск читает данные **блоками** (обычно 4 КБ или 8 КБ). Даже если нам нужен 1 байт, с диска прочитается целый блок.

Идея: **пусть один узел занимает один блок**! Тогда в узле можно хранить **сотни или тысячи ключей**.

Если узел хранит 1000 ключей, то дерево с n = 10⁹:

```
h = log₁₀₀₁(10⁹) ≈ log(10⁹) / log(1001) ≈ 9 / 3 = 3
```

**Три обращения к диску** вместо 43! При 10 мс на обращение — **0.03 секунды**.

Именно эту идею реализует **B-дерево**.

## Глава 22. Основы B-дерева

### 22.1 История

В 1970 году **Рудольф Байер** и **Эдвард Маккрейт**, работая в Boeing Scientific Research Labs, изобрели B-дерево. Что означает буква "B" — доподлинно неизвестно. Версии: Boeing, Balanced, Bayer, Broad.

### 22.2 Определение

> **B-дерево порядка t** (минимальная степень t ≥ 2) — это корневое дерево поиска, в котором:

| # | Свойство | Подробности |
|---|----------|-------------|
| 1 | Каждый узел хранит **от t−1 до 2t−1 ключей** | Кроме корня, который может хранить от 1 ключа |
| 2 | Ключи в узле **отсортированы** | key₁ < key₂ < ... < keyₖ |
| 3 | Каждый внутренний узел с k ключами имеет **k+1 дочерних узлов** | Дети «вклиниваются» между ключами |
| 4 | Все **листья на одной глубине** | Дерево идеально сбалансировано по глубине |
| 5 | Корень имеет **от 1 до 2t−1 ключей** (от 2 до 2t детей, если не лист) | Менее строгое ограничение |

Параметр t называют **минимальной степенью**. Частные случаи:
- t = 2 → узел хранит от 1 до 3 ключей → это **2-3-4 дерево**
- t = 3 → от 2 до 5 ключей
- t = 1000 → от 999 до 1999 ключей (типично для дисковых БД)

### 22.3 Свойство поиска

Для узла с ключами key₁ < key₂ < ... < keyₖ и детьми c₀, c₁, ..., cₖ:

```
Все ключи в c₀  <  key₁  <  все ключи в c₁  <  key₂  <  ...  <  keyₖ  <  все ключи в cₖ
```

Визуально для узла с 3 ключами:

```
        [ key₁ | key₂ | key₃ ]
       /    |       |       \
     c₀    c₁     c₂       c₃

  всё < key₁   key₁..key₂   key₂..key₃   всё > key₃
```

### 22.4 Визуальный пример

B-дерево порядка t=2 (2-3-4 дерево) с ключами 1–16:

```
                    [8]
                  /      \
          [4]              [12]
         /   \            /    \
    [2]     [6]      [10]     [14]
   / \     / \       / \      /  \
 [1] [3] [5] [7]  [9] [11] [13] [15,16]
```

Каждый внутренний узел имеет от 2 до 4 детей. Все листья на глубине 3.

### 22.5 Высота B-дерева

**Теорема:** B-дерево порядка t с n ≥ 1 ключами имеет высоту:

```
h ≤ log_t((n+1)/2)
```

*Доказательство:*
- На глубине 0 — корень с ≥ 1 ключом, ≥ 2 детей
- На глубине 1 — ≥ 2 узла с ≥ t−1 ключами каждый, ≥ 2t детей
- На глубине d — ≥ 2·tᵈ⁻¹ узлов
- Итого узлов на всех глубинах: n ≥ 1 + (t−1)·Σ(2·tⁱ⁻¹) для i=1..h
- Упрощаем: n ≥ 2tʰ − 1, откуда h ≤ log_t((n+1)/2)

**Примеры:**

| n | t = 2 | t = 100 | t = 1000 |
|---|-------|---------|----------|
| 10³ | 10 | 2 | 1 |
| 10⁶ | 20 | 3 | 2 |
| 10⁹ | 30 | **5** | **3** |
| 10¹² | 40 | 6 | 4 |

При t = 1000 и миллиарде ключей — всего **3 уровня**!

### 22.6 Структура узла

```cpp
struct BTreeNode {
    int n;              // текущее число ключей
    int* keys;          // массив ключей [0..n-1]
    BTreeNode** children; // массив детей [0..n]
    bool leaf;          // является ли листом

    BTreeNode(int t, bool isLeaf) : n(0), leaf(isLeaf) {
        keys = new int[2 * t - 1];
        children = new BTreeNode*[2 * t];
    }
};

struct BTree {
    BTreeNode* root;
    int t;  // минимальная степень

    BTree(int t) : t(t), root(nullptr) {}
};
```

## Глава 23. Поиск в B-дереве

### 23.1 Алгоритм

Поиск в B-дереве — естественное обобщение поиска в BST:

1. В текущем узле ищем позицию ключа (линейно или бинарно)
2. Если нашли — возвращаем
3. Если не нашли — спускаемся в соответствующего ребёнка
4. Если дошли до листа и не нашли — ключа нет

```cpp
BTreeNode* search(BTreeNode* v, int key) {
    // Находим первый ключ >= key
    int i = 0;
    while (i < v->n && key > v->keys[i]) {
        i++;
    }

    // Нашли ключ
    if (i < v->n && key == v->keys[i]) {
        return v;
    }

    // Дошли до листа — ключа нет
    if (v->leaf) {
        return nullptr;
    }

    // Спускаемся в ребёнка
    // (здесь было бы дисковое чтение: disk_read(v->children[i]))
    return search(v->children[i], key);
}
```

### 23.2 Сложность

- **Дисковых чтений:** O(h) = O(log_t n) — по одному на каждый уровень
- **Сравнений в памяти:** O(t · h) = O(t · log_t n) при линейном поиске, или O(log(t) · log_t(n)) = O(log n) при бинарном поиске внутри узла
- **Главное:** число дисковых операций минимально!

### 23.3 Пошаговый пример

Ищем ключ 14 в B-дереве (t=3):

```
Уровень 0 (корень):  [10, 20]
                     /   |    \

Сравниваем: 14 > 10, 14 < 20 → идём в среднего ребёнка (c₁)

Уровень 1:  [13, 15, 17]
            / |    |    \

Сравниваем: 14 > 13, 14 < 15 → идём в c₁

Уровень 2 (лист):  [14]

Нашли! Итого: 3 дисковых чтения.
```

## Глава 24. Вставка в B-дерево

### 24.1 Базовая идея

В B-дереве вставка **всегда** происходит в лист (в отличие от BST, где новый узел может стать в любом месте). Но лист может быть **полным** (содержать 2t−1 ключей). Тогда нужно его **разбить**.

### 24.2 Операция Split: разбиение полного узла

Если узел содержит 2t−1 ключей (полный), разбиваем его на два:

```
До (полный узел, t=3, 5 ключей):

        parent
          |
    [1, 3, 5, 7, 9]     ← 2t-1 = 5 ключей

После (split):

        parent
        .. 5 ..          ← средний ключ поднимается к родителю
       /       \
    [1, 3]   [7, 9]     ← каждый получает t-1 = 2 ключа
```

Код:

```cpp
// Разбивает полного ребёнка children[i] узла v
void splitChild(BTreeNode* v, int i) {
    BTreeNode* fullChild = v->children[i];
    BTreeNode* newNode = new BTreeNode(t, fullChild->leaf);
    newNode->n = t - 1;

    // Копируем правую половину ключей в новый узел
    for (int j = 0; j < t - 1; j++) {
        newNode->keys[j] = fullChild->keys[j + t];
    }

    // Копируем правую половину детей (если не лист)
    if (!fullChild->leaf) {
        for (int j = 0; j < t; j++) {
            newNode->children[j] = fullChild->children[j + t];
        }
    }

    fullChild->n = t - 1;

    // Сдвигаем детей и ключи родителя, чтобы вставить новый узел
    for (int j = v->n; j > i; j--) {
        v->children[j + 1] = v->children[j];
    }
    v->children[i + 1] = newNode;

    for (int j = v->n - 1; j >= i; j--) {
        v->keys[j + 1] = v->keys[j];
    }
    v->keys[i] = fullChild->keys[t - 1];  // средний ключ
    v->n++;
}
```

### 24.3 Проактивный подход (один проход сверху вниз)

Классический подход (из Кормена): при спуске к листу **заранее** разбиваем все полные узлы на пути. Это гарантирует, что когда мы дойдём до листа, в нём будет место для вставки.

```cpp
void insert(BTree& tree, int key) {
    if (!tree.root) {
        tree.root = new BTreeNode(tree.t, true);
        tree.root->keys[0] = key;
        tree.root->n = 1;
        return;
    }

    // Если корень полный — разбиваем его (дерево растёт в высоту)
    if (tree.root->n == 2 * tree.t - 1) {
        BTreeNode* newRoot = new BTreeNode(tree.t, false);
        newRoot->children[0] = tree.root;
        splitChild(newRoot, 0);
        tree.root = newRoot;

        // Определяем, в какого ребёнка идти
        int i = (key > newRoot->keys[0]) ? 1 : 0;
        insertNonFull(newRoot->children[i], key);
    } else {
        insertNonFull(tree.root, key);
    }
}

void insertNonFull(BTreeNode* v, int key) {
    int i = v->n - 1;

    if (v->leaf) {
        // Вставляем ключ в отсортированную позицию
        while (i >= 0 && key < v->keys[i]) {
            v->keys[i + 1] = v->keys[i];
            i--;
        }
        v->keys[i + 1] = key;
        v->n++;
        // disk_write(v)
    } else {
        // Находим ребёнка, в которого нужно идти
        while (i >= 0 && key < v->keys[i]) {
            i--;
        }
        i++;
        // disk_read(v->children[i])

        // Если ребёнок полный — разбиваем его ДО спуска
        if (v->children[i]->n == 2 * t - 1) {
            splitChild(v, i);
            if (key > v->keys[i]) {
                i++;
            }
        }
        insertNonFull(v->children[i], key);
    }
}
```

### 24.4 Рост дерева

B-дерево растёт в высоту **только** при разбиении корня. Это единственный случай, когда высота увеличивается на 1. Дерево растёт **вверх**, а не вниз!

```
До:    [1, 2, 3, 4, 5]    (полный корень, t=3)

После разбиения корня:

           [3]             ← новый корень
          /   \
      [1, 2]  [4, 5]

Высота была 0, стала 1.
```

### 24.5 Пошаговый пример

B-дерево с t=2 (2-3-4 дерево). Вставляем: 10, 20, 30, 40, 50, 60, 70

```
Шаг 1: вставка 10
    [10]

Шаг 2: вставка 20
    [10, 20]

Шаг 3: вставка 30
    [10, 20, 30]    ← полный (2t-1 = 3 ключа)

Шаг 4: вставка 40 → корень полный, разбиваем!
           [20]
          /    \
       [10]   [30]

    Теперь вставляем 40 в правый лист:
           [20]
          /    \
       [10]   [30, 40]

Шаг 5: вставка 50
           [20]
          /    \
       [10]   [30, 40, 50]    ← правый лист полный

Шаг 6: вставка 60 → правый лист полный, разбиваем!
           [20, 40]
          /   |    \
       [10] [30]  [50]

    Вставляем 60:
           [20, 40]
          /   |    \
       [10] [30]  [50, 60]

Шаг 7: вставка 70
           [20, 40]
          /   |    \
       [10] [30]  [50, 60, 70]    ← правый лист полный

    Но мы не вставляем ещё — просто дерево готово для
    следующей вставки с разбиением.
```

## Глава 25. Удаление из B-дерева

Удаление — самая сложная операция в B-дереве. Нужно гарантировать, что после удаления ни один узел не содержит меньше t−1 ключей.

### 25.1 Три основных случая

**Случай 1: Ключ находится в листе**

Просто удаляем ключ из листа. Если в листе было > t−1 ключей, всё хорошо.

```
Удаляем 3 из листа [1, 3, 5]:
    → [1, 5]    (было 3 ключа, стало 2, при t=2 минимум 1 — OK)
```

**Случай 2: Ключ находится во внутреннем узле**

Нельзя просто удалить ключ из внутреннего узла — нарушится структура. Три подслучая:

**2a:** Если левый ребёнок y содержит ≥ t ключей → находим **предшественника** k' (максимальный ключ в поддереве y), заменяем удаляемый ключ на k', рекурсивно удаляем k' из y.

```
Удаляем 13 из [7, 13]:
    Левый ребёнок [10, 11, 12] имеет ≥ t ключей
    Предшественник = 12
    Заменяем 13 на 12, удаляем 12 из ребёнка

    [7, 13]  →  [7, 12]
```

**2b:** Если правый ребёнок z содержит ≥ t ключей → аналогично с **преемником**.

**2c:** Если оба ребёнка имеют ровно t−1 ключей → **сливаем** их: ключ из родителя + все ключи левого и правого ребёнка → один узел с 2t−1 ключами. Затем рекурсивно удаляем из объединённого узла.

**Случай 3: Ключ не в текущем узле, нужно спуститься в ребёнка**

Перед спуском гарантируем, что ребёнок имеет ≥ t ключей (а не минимальные t−1). Если у него ровно t−1:

**3a: Заимствование у брата.** Если соседний брат имеет ≥ t ключей → «поворот через родителя»:

```
До (ребёнок c₁ имеет t-1 = 1 ключ, брат c₂ имеет 3):

    parent: [... 20 ...]
              |      |
           c₁:[10]  c₂:[25, 30, 35]

После заимствования:

    parent: [... 25 ...]
              |      |
        c₁:[10, 20]  c₂:[30, 35]

Ключ 20 спустился из родителя в c₁, ключ 25 поднялся из c₂ в родителя.
```

**3b: Слияние.** Если оба соседних брата имеют ровно t−1 ключей → сливаем ребёнка с братом и ключом-разделителем из родителя:

```
До:
    parent: [... 20 ...]
              |      |
           c₁:[10]  c₂:[30]

После слияния:
    parent: [... ...]        ← ключ 20 ушёл вниз
              |
         merged:[10, 20, 30]
```

### 25.2 Проактивный подход

Как и при вставке, при спуске мы **заранее** гарантируем, что текущий узел имеет ≥ t ключей (чтобы можно было безопасно удалить). Это позволяет сделать всё за один проход.

### 25.3 Код удаления

```cpp
void remove(BTreeNode* v, int key) {
    int i = 0;
    while (i < v->n && v->keys[i] < key) i++;

    if (i < v->n && v->keys[i] == key) {
        // Ключ найден в этом узле
        if (v->leaf) {
            // Случай 1: ключ в листе — просто удаляем
            for (int j = i; j < v->n - 1; j++)
                v->keys[j] = v->keys[j + 1];
            v->n--;
        } else {
            // Случай 2: ключ во внутреннем узле
            if (v->children[i]->n >= t) {
                // 2a: берём предшественника из левого ребёнка
                int pred = getPredecessor(v, i);
                v->keys[i] = pred;
                remove(v->children[i], pred);
            } else if (v->children[i + 1]->n >= t) {
                // 2b: берём преемника из правого ребёнка
                int succ = getSuccessor(v, i);
                v->keys[i] = succ;
                remove(v->children[i + 1], succ);
            } else {
                // 2c: оба ребёнка имеют t-1 ключей — сливаем
                mergeChildren(v, i);
                remove(v->children[i], key);
            }
        }
    } else {
        // Ключ не в этом узле — спускаемся в ребёнка
        if (v->leaf) return;  // ключа нет в дереве

        bool lastChild = (i == v->n);

        // Гарантируем, что ребёнок имеет >= t ключей
        if (v->children[i]->n < t) {
            fill(v, i);  // заимствование или слияние (случаи 3a, 3b)
        }

        // После fill индекс мог измениться
        if (lastChild && i > v->n) {
            remove(v->children[i - 1], key);
        } else {
            remove(v->children[i], key);
        }
    }
}

int getPredecessor(BTreeNode* v, int i) {
    BTreeNode* cur = v->children[i];
    while (!cur->leaf)
        cur = cur->children[cur->n];
    return cur->keys[cur->n - 1];
}

int getSuccessor(BTreeNode* v, int i) {
    BTreeNode* cur = v->children[i + 1];
    while (!cur->leaf)
        cur = cur->children[0];
    return cur->keys[0];
}

void mergeChildren(BTreeNode* v, int i) {
    BTreeNode* left = v->children[i];
    BTreeNode* right = v->children[i + 1];

    // Средний ключ из родителя → в левого ребёнка
    left->keys[t - 1] = v->keys[i];

    // Копируем ключи правого → в левого
    for (int j = 0; j < right->n; j++)
        left->keys[j + t] = right->keys[j];

    // Копируем детей правого → в левого
    if (!left->leaf) {
        for (int j = 0; j <= right->n; j++)
            left->children[j + t] = right->children[j];
    }

    // Сдвигаем ключи и детей родителя
    for (int j = i; j < v->n - 1; j++) {
        v->keys[j] = v->keys[j + 1];
        v->children[j + 1] = v->children[j + 2];
    }

    left->n = 2 * t - 1;
    v->n--;

    delete right;
}

void fill(BTreeNode* v, int i) {
    if (i > 0 && v->children[i - 1]->n >= t) {
        // Заимствуем у левого брата
        borrowFromLeft(v, i);
    } else if (i < v->n && v->children[i + 1]->n >= t) {
        // Заимствуем у правого брата
        borrowFromRight(v, i);
    } else {
        // Сливаем с братом
        if (i < v->n)
            mergeChildren(v, i);
        else
            mergeChildren(v, i - 1);
    }
}

void borrowFromLeft(BTreeNode* v, int i) {
    BTreeNode* child = v->children[i];
    BTreeNode* leftSibling = v->children[i - 1];

    // Сдвигаем ключи ребёнка вправо
    for (int j = child->n - 1; j >= 0; j--)
        child->keys[j + 1] = child->keys[j];
    if (!child->leaf) {
        for (int j = child->n; j >= 0; j--)
            child->children[j + 1] = child->children[j];
    }

    // Ключ из родителя → в ребёнка
    child->keys[0] = v->keys[i - 1];

    // Последний ребёнок левого брата → первый ребёнок child
    if (!child->leaf)
        child->children[0] = leftSibling->children[leftSibling->n];

    // Последний ключ левого брата → в родителя
    v->keys[i - 1] = leftSibling->keys[leftSibling->n - 1];

    child->n++;
    leftSibling->n--;
}

void borrowFromRight(BTreeNode* v, int i) {
    BTreeNode* child = v->children[i];
    BTreeNode* rightSibling = v->children[i + 1];

    // Ключ из родителя → в конец ребёнка
    child->keys[child->n] = v->keys[i];

    // Первый ребёнок правого брата → последний ребёнок child
    if (!child->leaf)
        child->children[child->n + 1] = rightSibling->children[0];

    // Первый ключ правого брата → в родителя
    v->keys[i] = rightSibling->keys[0];

    // Сдвигаем ключи и детей правого брата влево
    for (int j = 0; j < rightSibling->n - 1; j++)
        rightSibling->keys[j] = rightSibling->keys[j + 1];
    if (!rightSibling->leaf) {
        for (int j = 0; j < rightSibling->n; j++)
            rightSibling->children[j] = rightSibling->children[j + 1];
    }

    child->n++;
    rightSibling->n--;
}
```

### 25.4 Уменьшение высоты

Если после удаления корень стал пустым (0 ключей), его единственный ребёнок становится новым корнём. Высота дерева уменьшается на 1:

```cpp
void remove(BTree& tree, int key) {
    if (!tree.root) return;

    remove(tree.root, key);

    // Если корень опустел
    if (tree.root->n == 0) {
        BTreeNode* oldRoot = tree.root;
        if (tree.root->leaf) {
            tree.root = nullptr;
        } else {
            tree.root = tree.root->children[0];
        }
        delete oldRoot;
    }
}
```

## Глава 26. Варианты B-деревьев

### 26.1 B⁺-дерево

**B⁺-дерево** — самый практически важный вариант. Отличия от B-дерева:

| Свойство            | B-дерево                   | B⁺-дерево                                            |
| ------------------- | -------------------------- | ---------------------------------------------------- |
| Где хранятся данные | Во **всех** узлах          | Только в **листьях**                                 |
| Внутренние узлы     | Ключи + данные + указатели | Только ключи-**разделители** + указатели             |
| Дублирование ключей | Нет                        | Да (ключ может быть и в листе, и во внутреннем узле) |
| Листья связаны?     | Нет                        | **Да** — односвязным или двусвязным списком          |
| Range-запросы       | O(h + k), сложнее          | **O(h + k)**, проще — идём по листьям                |

Визуально:

```
B⁺-дерево (t=2):

Внутренние узлы (только разделители):
                   [15]
                  /     \
            [5, 10]     [20, 25]

Листья (данные + связный список):
[1,3,5] → [7,8,10] → [12,14,15] → [17,19,20] → [22,24,25] → [27,30]
```

**Почему B⁺-дерево лучше для баз данных:**

1. **Внутренние узлы компактнее** — хранят только ключи, без данных. Значит, больше ключей помещается в один блок → дерево ниже → меньше дисковых чтений

2. **Range-scan** — чтобы получить все записи с ключами от 10 до 100, достаточно найти лист с ключом 10 и идти по связному списку листьев. Не нужно подниматься и спускаться по дереву

3. **Предсказуемая производительность** — все данные на одной глубине (в листьях), время поиска всегда одинаково

### 26.2 B*-дерево

**B\*-дерево** — модификация, где узлы заполнены минимум на **2/3** (вместо 1/2 в обычном B-дереве):

- Каждый узел содержит от ⌈(2·(2t−1))/3⌉ до 2t−1 ключей
- Перед разбиением переполненного узла сначала пытаемся **перераспределить** ключи с соседом
- Разбиение происходит из **двух** полных узлов в **три** — реже, чем в B-дереве

Преимущество: лучшая утилизация памяти (узлы заполнены плотнее).

### 26.3 Связь с красно-чёрным деревом

B-дерево порядка t=2 — это **2-3-4 дерево**. Красно-чёрное дерево — это бинарное представление 2-3-4 дерева:

```
2-узел (1 ключ, 2 ребёнка):
    [B]        ↔    (B)        чёрный узел
   /   \           /   \

3-узел (2 ключа, 3 ребёнка):
   [A, B]      ↔      (B)      чёрный узел
  / |   \            /   \
                   (A)    ...   красный левый ребёнок
                  /   \

4-узел (3 ключа, 4 ребёнка):
  [A, B, C]    ↔      (B)      чёрный узел
 / | |   \          /     \
                  (A)     (C)   два красных ребёнка
                 /   \   /   \
```

Это объясняет, **откуда берутся 5 свойств** красно-чёрного дерева — они обеспечивают корректное отображение 2-3-4 дерева.

## Глава 27. Анализ и практика B-дерева

### 27.1 Сводка сложностей

| Операция | Дисковых чтений | Операций в RAM |
|----------|----------------|----------------|
| Поиск | O(log_t n) | O(t · log_t n) |
| Вставка | O(log_t n) | O(t · log_t n) |
| Удаление | O(log_t n) | O(t · log_t n) |

### 27.2 Выбор параметра t

Цель: один узел = один дисковый блок.

```
Размер блока = 4096 байт (типичный)
Размер ключа = 8 байт (int64)
Размер указателя на ребёнка = 8 байт (адрес на диске)
Размер данных = 0 (B⁺-дерево, данные только в листьях)

Узел с k ключами:  k × 8 (ключи) + (k+1) × 8 (указатели) ≤ 4096
                    16k + 8 ≤ 4096
                    k ≤ 255

Значит t = 128 (максимальная степень ≈ 255, минимальная ≈ 128)
```

При t = 128 и n = 10⁹:

```
h ≤ log₁₂₈(5·10⁸) ≈ 4.1 → h = 5
```

Пять дисковых чтений для поиска среди **миллиарда** записей. При кэшировании корня и первого уровня — **3 чтения**.

### 27.3 Где используется B-дерево

| Система | Вариант | Для чего |
|---------|---------|----------|
| **MySQL (InnoDB)** | B⁺-дерево | Первичные и вторичные индексы |
| **PostgreSQL** | B⁺-дерево | Индексы (основной тип) |
| **SQLite** | B⁺-дерево | Таблицы и индексы |
| **Oracle** | B⁺-дерево | Индексы |
| **MongoDB** | B⁺-дерево (WiredTiger) | Индексы |
| **NTFS** | B⁺-дерево | Директории, MFT |
| **HFS+** | B⁺-дерево | Каталог файлов |
| **ext4** | H-tree (модификация B-дерева) | Директории |
| **Btrfs** | B-дерево (copy-on-write) | Вся файловая система |

### 27.4 B-дерево vs LSM-дерево

Современные системы (LevelDB, RocksDB, Cassandra) используют **LSM-дерево** (Log-Structured Merge Tree) вместо B-дерева:

| Критерий | B-дерево | LSM-дерево |
|----------|---------|------------|
| Чтение | ⭐ Быстрее | Медленнее (проверка нескольких уровней) |
| Запись | Медленнее (случайные записи) | ⭐ Быстрее (последовательные записи) |
| Нагрузка | Чтение-тяжёлая (OLTP) | Запись-тяжёлая (логи, метрики) |
| Примеры | MySQL, PostgreSQL | RocksDB, Cassandra, LevelDB |

### 27.5 Полная реализация на C++

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int T = 3;  // минимальная степень

struct BTreeNode {
    int keys[2 * T - 1];
    BTreeNode* children[2 * T];
    int n;
    bool leaf;

    BTreeNode(bool isLeaf = true) : n(0), leaf(isLeaf) {
        for (int i = 0; i < 2 * T; i++) children[i] = nullptr;
    }
};

class BTree {
    BTreeNode* root;

    void splitChild(BTreeNode* parent, int i) {
        BTreeNode* full = parent->children[i];
        BTreeNode* newNode = new BTreeNode(full->leaf);
        newNode->n = T - 1;

        for (int j = 0; j < T - 1; j++)
            newNode->keys[j] = full->keys[j + T];

        if (!full->leaf) {
            for (int j = 0; j < T; j++)
                newNode->children[j] = full->children[j + T];
        }

        full->n = T - 1;

        for (int j = parent->n; j > i; j--)
            parent->children[j + 1] = parent->children[j];
        parent->children[i + 1] = newNode;

        for (int j = parent->n - 1; j >= i; j--)
            parent->keys[j + 1] = parent->keys[j];
        parent->keys[i] = full->keys[T - 1];
        parent->n++;
    }

    void insertNonFull(BTreeNode* v, int key) {
        int i = v->n - 1;
        if (v->leaf) {
            while (i >= 0 && key < v->keys[i]) {
                v->keys[i + 1] = v->keys[i];
                i--;
            }
            v->keys[i + 1] = key;
            v->n++;
        } else {
            while (i >= 0 && key < v->keys[i]) i--;
            i++;
            if (v->children[i]->n == 2 * T - 1) {
                splitChild(v, i);
                if (key > v->keys[i]) i++;
            }
            insertNonFull(v->children[i], key);
        }
    }

    int getPred(BTreeNode* v, int i) {
        BTreeNode* cur = v->children[i];
        while (!cur->leaf) cur = cur->children[cur->n];
        return cur->keys[cur->n - 1];
    }

    int getSucc(BTreeNode* v, int i) {
        BTreeNode* cur = v->children[i + 1];
        while (!cur->leaf) cur = cur->children[0];
        return cur->keys[0];
    }

    void merge(BTreeNode* v, int i) {
        BTreeNode* left = v->children[i];
        BTreeNode* right = v->children[i + 1];

        left->keys[T - 1] = v->keys[i];

        for (int j = 0; j < right->n; j++)
            left->keys[j + T] = right->keys[j];
        if (!left->leaf) {
            for (int j = 0; j <= right->n; j++)
                left->children[j + T] = right->children[j];
        }

        for (int j = i; j < v->n - 1; j++) {
            v->keys[j] = v->keys[j + 1];
            v->children[j + 1] = v->children[j + 2];
        }

        left->n = 2 * T - 1;
        v->n--;
        delete right;
    }

    void borrowFromLeft(BTreeNode* v, int i) {
        BTreeNode* child = v->children[i];
        BTreeNode* sibling = v->children[i - 1];

        for (int j = child->n - 1; j >= 0; j--)
            child->keys[j + 1] = child->keys[j];
        if (!child->leaf) {
            for (int j = child->n; j >= 0; j--)
                child->children[j + 1] = child->children[j];
        }

        child->keys[0] = v->keys[i - 1];
        if (!child->leaf)
            child->children[0] = sibling->children[sibling->n];
        v->keys[i - 1] = sibling->keys[sibling->n - 1];

        child->n++;
        sibling->n--;
    }

    void borrowFromRight(BTreeNode* v, int i) {
        BTreeNode* child = v->children[i];
        BTreeNode* sibling = v->children[i + 1];

        child->keys[child->n] = v->keys[i];
        if (!child->leaf)
            child->children[child->n + 1] = sibling->children[0];
        v->keys[i] = sibling->keys[0];

        for (int j = 0; j < sibling->n - 1; j++)
            sibling->keys[j] = sibling->keys[j + 1];
        if (!sibling->leaf) {
            for (int j = 0; j < sibling->n; j++)
                sibling->children[j] = sibling->children[j + 1];
        }

        child->n++;
        sibling->n--;
    }

    void fill(BTreeNode* v, int i) {
        if (i > 0 && v->children[i - 1]->n >= T)
            borrowFromLeft(v, i);
        else if (i < v->n && v->children[i + 1]->n >= T)
            borrowFromRight(v, i);
        else {
            if (i < v->n) merge(v, i);
            else merge(v, i - 1);
        }
    }

    void removeFromNode(BTreeNode* v, int key) {
        int i = 0;
        while (i < v->n && v->keys[i] < key) i++;

        if (i < v->n && v->keys[i] == key) {
            if (v->leaf) {
                for (int j = i; j < v->n - 1; j++)
                    v->keys[j] = v->keys[j + 1];
                v->n--;
            } else if (v->children[i]->n >= T) {
                int pred = getPred(v, i);
                v->keys[i] = pred;
                removeFromNode(v->children[i], pred);
            } else if (v->children[i + 1]->n >= T) {
                int succ = getSucc(v, i);
                v->keys[i] = succ;
                removeFromNode(v->children[i + 1], succ);
            } else {
                merge(v, i);
                removeFromNode(v->children[i], key);
            }
        } else {
            if (v->leaf) return;
            bool lastChild = (i == v->n);
            if (v->children[i]->n < T) fill(v, i);
            if (lastChild && i > v->n)
                removeFromNode(v->children[i - 1], key);
            else
                removeFromNode(v->children[i], key);
        }
    }

    void printNode(BTreeNode* v, int indent) {
        if (!v) return;
        cout << string(indent, ' ') << "[";
        for (int i = 0; i < v->n; i++) {
            if (i > 0) cout << ", ";
            cout << v->keys[i];
        }
        cout << "]" << (v->leaf ? " (leaf)" : "") << endl;

        if (!v->leaf) {
            for (int i = 0; i <= v->n; i++)
                printNode(v->children[i], indent + 4);
        }
    }

public:
    BTree() : root(nullptr) {}

    BTreeNode* search(int key) {
        if (!root) return nullptr;
        BTreeNode* v = root;
        while (v) {
            int i = 0;
            while (i < v->n && key > v->keys[i]) i++;
            if (i < v->n && key == v->keys[i]) return v;
            if (v->leaf) return nullptr;
            v = v->children[i];
        }
        return nullptr;
    }

    void insert(int key) {
        if (!root) {
            root = new BTreeNode(true);
            root->keys[0] = key;
            root->n = 1;
            return;
        }

        if (root->n == 2 * T - 1) {
            BTreeNode* newRoot = new BTreeNode(false);
            newRoot->children[0] = root;
            splitChild(newRoot, 0);
            root = newRoot;
            int i = (key > root->keys[0]) ? 1 : 0;
            insertNonFull(root->children[i], key);
        } else {
            insertNonFull(root, key);
        }
    }

    void remove(int key) {
        if (!root) return;
        removeFromNode(root, key);
        if (root->n == 0) {
            BTreeNode* old = root;
            root = root->leaf ? nullptr : root->children[0];
            delete old;
        }
    }

    void print() {
        printNode(root, 0);
        cout << endl;
    }
};

int main() {
    BTree tree;

    for (int i = 1; i <= 20; i++)
        tree.insert(i);

    cout << "After inserting 1..20:" << endl;
    tree.print();

    for (int x : {6, 13, 7, 4, 2, 16})
        tree.remove(x);

    cout << "After removing 6, 13, 7, 4, 2, 16:" << endl;
    tree.print();

    cout << "Search 10: " << (tree.search(10) ? "found" : "not found") << endl;
    cout << "Search 13: " << (tree.search(13) ? "found" : "not found") << endl;

    return 0;
}
```
