## Глава 9. Основы декартова дерева

### 9.1 История и названия

В 1989 году **Сесилия Арагон** и **Раймунд Сидель** предложили элегантную структуру данных, объединяющую **дерево поиска** (tree) и **кучу** (heap). Они назвали её **treap** — от слияния слов tree + heap.

В русскоязычной традиции эту структуру часто называют **декартово дерево** — потому что каждый узел определяется **парой** (x, y), как точка на декартовой плоскости:
- **x** — ключ (по горизонтали, свойство BST)
- **y** — приоритет (по вертикали, свойство кучи)

### 9.2 Определение

> **Декартово дерево (Treap)** — это бинарное дерево, в котором каждый узел хранит пару **(key, priority)**, и выполняются два свойства одновременно:
>
> 1. **По ключам** — бинарное дерево поиска (BST): для каждого узла все ключи в левом поддереве меньше, все в правом — больше
> 2. **По приоритетам** — куча (heap): приоритет каждого узла ≥ приоритетов его детей (max-heap)

Визуально:

```
         (5, 90)          ← максимальный приоритет в корне
        /       \
   (2, 70)    (8, 50)
   /    \         \
(1,30) (4,60)   (9,10)
```

Проверь:
- BST по ключам: 1 < 2 < 4 < 5 < 8 < 9 ✓
- Heap по приоритетам: 90 > 70, 90 > 50, 70 > 30, 70 > 60, 50 > 10 ✓

### 9.3 Ключевая теорема: единственность

> **Теорема:** Если все ключи и все приоритеты попарно различны, то декартово дерево **единственно** — существует ровно одно дерево, удовлетворяющее обоим свойствам.

*Доказательство (конструктивное):*
1. Корень — узел с наибольшим приоритетом (свойство кучи)
2. Все узлы с ключами меньше корня идут в левое поддерево (свойство BST)
3. Все узлы с ключами больше корня — в правое
4. Рекурсивно повторяем для поддеревьев

Это же доказывает, что структура treap полностью определяется набором пар (key, priority).

### 9.4 Случайные приоритеты → O(log n) в среднем

Главная идея: если приоритеты выбираются **случайно**, то treap по структуре эквивалентен **случайному BST** (BST, полученному вставкой ключей в случайном порядке).

Почему? Вспомни конструкцию из теоремы: корень — узел с максимальным приоритетом. Если приоритеты случайны, то каждый из n узлов с равной вероятностью 1/n станет корнем. Это в точности то, что происходит при случайной вставке.

**Известный результат:** ожидаемая высота случайного BST с n узлами равна **O(log n)** (точнее, ~4.31·ln(n) ≈ 2.99·log₂(n)).

> **Все операции в treap со случайными приоритетами работают за O(log n) в среднем.**

«В среднем» здесь означает: для **любой** последовательности операций, **усреднение по случайным приоритетам**. Это сильнее, чем «в среднем по входным данным».

### 9.5 Структура узла

```cpp
struct Node {
    int key;
    int priority;
    Node* left;
    Node* right;

    Node(int k) : key(k), priority(rand()), left(nullptr), right(nullptr) {}
};
```

Обрати внимание: приоритет генерируется **случайно** при создании узла. Это всё, что нужно для баланса — никаких поворотов, перекрасок или подсчёта высоты!

### 9.6 Сравнение подходов к балансировке

| | AVL | Красно-чёрное | Treap |
|---|---|---|---|
| Что хранит узел | height | color + parent | priority |
| Инвариант | Разница высот ≤ 1 | 5 цветовых свойств | BST + Heap |
| Баланс | Детерминированный | Детерминированный | **Вероятностный** |
| Механизм | Повороты при нарушении | Повороты + перекраска | Split / Merge |

## Глава 10. Операция Split (Разрезание)

### 10.1 Идея

**Split(T, k)** — разрезать дерево T на два:
- **L** — все узлы с ключами **< k**
- **R** — все узлы с ключами **≥ k**

(Вариант: можно разделить по ≤ k и > k — зависит от реализации.)

Это фундаментальная операция, на которой строятся вставка, удаление и многое другое.

### 10.2 Рекурсивный алгоритм

Рассмотрим корень дерева T:

**Случай 1:** key корня < k
```
Корень и его левое поддерево целиком идут в L.
Правое поддерево нужно рекурсивно разрезать.

        root           L:        root         R: R'
       /    \    →         /    \
     left  right        left    L'
     
Split(right, k) → (L', R')
root->right = L'
L = root, R = R'
```

**Случай 2:** key корня ≥ k
```
Корень и его правое поддерево целиком идут в R.
Левое поддерево нужно рекурсивно разрезать.

        root           L: L'    R:    root
       /    \    →                   /    \
     left  right                   R'   right

Split(left, k) → (L', R')
root->left = R'
L = L', R = root
```

### 10.3 Код

```cpp
// Разрезает дерево t на L (ключи < key) и R (ключи >= key)
void split(Node* t, int key, Node*& L, Node*& R) {
    if (!t) {
        L = R = nullptr;
        return;
    }

    if (t->key < key) {
        split(t->right, key, t->right, R);
        L = t;
    } else {
        split(t->left, key, L, t->left);
        R = t;
    }
}
```

**Сложность:** O(h) — мы проходим по одному пути от корня до листа. При случайных приоритетах — O(log n) в среднем.

### 10.4 Визуализация

```
Split( дерево , k=6 ):

         (5, 90)                L:    (5, 90)       R:  (8, 50)
        /       \                    /    \                 \
   (2, 70)    (8, 50)         (2, 70)  (пусто)          (9, 10)
   /    \         \            /    \
(1,30) (4,60)   (9,10)     (1,30) (4,60)

Ключи < 6: {1, 2, 4, 5} → L
Ключи ≥ 6: {8, 9} → R
```

## Глава 11. Операция Merge (Слияние)

### 11.1 Идея

**Merge(L, R)** — объединить два дерева в одно.

**Предусловие:** все ключи в L **<** все ключи в R.

Это обратная операция к Split.

### 11.2 Рекурсивный алгоритм

Кто будет корнём объединённого дерева? Тот, у кого **больше приоритет** (свойство кучи):

**Случай 1:** priority(L) > priority(R)
```
Корнем будет L.
Его левое поддерево остаётся, правое — результат Merge(L->right, R).

  L                   L
 / \     →          /   \
A   B             A    Merge(B, R)
```

**Случай 2:** priority(L) ≤ priority(R)
```
Корнем будет R.
Его правое поддерево остаётся, левое — результат Merge(L, R->left).

       R                    R
      / \     →           /   \
     C   D          Merge(L, C)   D
```

### 11.3 Код

```cpp
// Объединяет L и R (все ключи L < все ключи R)
Node* merge(Node* L, Node* R) {
    if (!L) return R;
    if (!R) return L;

    if (L->priority > R->priority) {
        L->right = merge(L->right, R);
        return L;
    } else {
        R->left = merge(L, R->left);
        return R;
    }
}
```

**Сложность:** O(h_L + h_R) — в худшем случае проходим по правому «хребту» L и левому «хребту» R. При случайных приоритетах — O(log n) в среднем.

### 11.4 Свойство: Merge — обратная к Split

Если `Split(T, k)` даёт `(L, R)`, то `Merge(L, R)` восстанавливает исходное дерево T.

Это даёт мощную парадигму: любую операцию можно реализовать как **Split → модификация → Merge**.

## Глава 12. Операции через Split и Merge

### 12.1 Поиск

Поиск в treap — это обычный поиск в BST (приоритеты не нужны):

```cpp
Node* search(Node* t, int key) {
    if (!t) return nullptr;
    if (key == t->key) return t;
    if (key < t->key) return search(t->left, key);
    return search(t->right, key);
}
```

### 12.2 Вставка

**Способ 1: через Split + Merge** (элегантный)

```cpp
void insert(Node*& t, int key) {
    Node* L;
    Node* R;
    split(t, key, L, R);                 // L: ключи < key, R: ключи >= key
    Node* newNode = new Node(key);
    t = merge(merge(L, newNode), R);      // L + {newNode} + R
}
```

Если нужно проверить, что ключ не существует:

```cpp
void insert(Node*& t, int key) {
    if (search(t, key)) return;  // уже есть
    Node* L;
    Node* R;
    split(t, key, L, R);
    t = merge(merge(L, new Node(key)), R);
}
```

**Способ 2: рекурсивный с поворотами** (классический)

Вставляем как в BST, затем «всплываем» вверх поворотами, если приоритет нового узла больше:

```cpp
void insert(Node*& t, Node* newNode) {
    if (!t) {
        t = newNode;
        return;
    }

    if (newNode->priority > t->priority) {
        // newNode должен стать корнём — разрезаем t по ключу newNode
        split(t, newNode->key, newNode->left, newNode->right);
        t = newNode;
    } else if (newNode->key < t->key) {
        insert(t->left, newNode);
    } else {
        insert(t->right, newNode);
    }
}
```

### 12.3 Удаление

**Способ 1: через Split + Merge** (элегантный)

```cpp
void erase(Node*& t, int key) {
    if (!t) return;

    if (t->key == key) {
        // Нашли — заменяем узел слиянием его поддеревьев
        Node* temp = t;
        t = merge(t->left, t->right);
        delete temp;
    } else if (key < t->key) {
        erase(t->left, key);
    } else {
        erase(t->right, key);
    }
}
```

**Способ 2: через тройной Split**

```cpp
void erase(Node*& t, int key) {
    Node *L, *mid, *R;
    split(t, key, L, mid);           // L: < key, mid: >= key
    split(mid, key + 1, mid, R);     // mid: == key, R: > key
    delete mid;                       // удаляем узел
    t = merge(L, R);
}
```

### 12.4 Другие операции

Декартово дерево через Split/Merge легко поддерживает:

```cpp
// Объединение двух множеств (все ключи L < все ключи R)
Node* unite(Node* L, Node* R) {
    return merge(L, R);
}

// k-й по порядку элемент (если храним размер поддерева)
int kth(Node* t, int k) {
    int leftSize = getSize(t->left);
    if (k <= leftSize) return kth(t->left, k);
    if (k == leftSize + 1) return t->key;
    return kth(t->right, k - leftSize - 1);
}
```

## Глава 13. Неявный ключ (Implicit Key Treap)

### 13.1 Мотивация

Обычный treap хранит явные ключи — числа, строки и т.д. Но что, если мы хотим работать с **последовательностью** (массивом) и выполнять операции:

- Вставить элемент в позицию i
- Удалить элемент на позиции i
- Разрезать массив на две части
- Склеить два массива
- Перевернуть отрезок
- Найти сумму/минимум на отрезке

Массив делает всё это за O(n) (сдвиги!). Декартово дерево по неявному ключу — за **O(log n)**.

### 13.2 Идея

Вместо хранения ключа явно, **позиция** элемента в последовательности определяется **размером левого поддерева**:

```
Позиция узла v = size(v->left) + 1
(в контексте поддерева с корнем v)
```

Для этого в каждом узле храним **cnt** — размер поддерева:

```cpp
struct Node {
    int value;       // хранимое значение (не ключ!)
    int priority;
    int cnt;         // размер поддерева
    Node* left;
    Node* right;

    Node(int val) : value(val), priority(rand()),
                     cnt(1), left(nullptr), right(nullptr) {}
};

int getSize(Node* t) {
    return t ? t->cnt : 0;
}

void update(Node* t) {
    if (t) t->cnt = 1 + getSize(t->left) + getSize(t->right);
}
```

### 13.3 Split и Merge по неявному ключу

**Split(t, k)** — отделить первые k элементов:

```cpp
void split(Node* t, int k, Node*& L, Node*& R) {
    if (!t) { L = R = nullptr; return; }

    int leftSize = getSize(t->left);

    if (leftSize >= k) {
        // Разрез проходит через левое поддерево
        split(t->left, k, L, t->left);
        R = t;
    } else {
        // leftSize + 1 (текущий узел) элементов идут в L
        split(t->right, k - leftSize - 1, t->right, R);
        L = t;
    }
    update(t);
}
```

**Merge** — точно такой же, как для обычного treap, только с `update`:

```cpp
Node* merge(Node* L, Node* R) {
    if (!L) return R;
    if (!R) return L;

    if (L->priority > R->priority) {
        L->right = merge(L->right, R);
        update(L);
        return L;
    } else {
        R->left = merge(L, R->left);
        update(R);
        return R;
    }
}
```

### 13.4 Операции над массивом

**Вставка элемента val на позицию pos (0-indexed):**

```cpp
void insertAt(Node*& t, int pos, int val) {
    Node *L, *R;
    split(t, pos, L, R);
    t = merge(merge(L, new Node(val)), R);
}
```

**Удаление элемента на позиции pos:**

```cpp
void eraseAt(Node*& t, int pos) {
    Node *L, *mid, *R;
    split(t, pos, L, mid);
    split(mid, 1, mid, R);
    delete mid;
    t = merge(L, R);
}
```

**Получение элемента на позиции pos:**

```cpp
int getAt(Node* t, int pos) {
    int leftSize = getSize(t->left);
    if (pos < leftSize) return getAt(t->left, pos);
    if (pos == leftSize) return t->value;
    return getAt(t->right, pos - leftSize - 1);
}
```

### 13.5 Переворот отрезка (reverse)

Это «убийственная фича» неявного treap. Чтобы перевернуть отрезок \[l, r\]:

1. Split → получить три части: \[0..l-1\], \[l..r\], \[r+1..n-1\]
2. Пометить средний кусок флагом `rev = true`
3. Merge обратно

При спуске по дереву, если встречаем `rev = true`, обмениваем детей и проталкиваем флаг вниз:

```cpp
struct Node {
    int value, priority, cnt;
    bool rev;        // флаг «перевернуть»
    Node *left, *right;

    Node(int val) : value(val), priority(rand()),
        cnt(1), rev(false), left(nullptr), right(nullptr) {}
};

void push(Node* t) {
    if (t && t->rev) {
        swap(t->left, t->right);
        if (t->left) t->left->rev ^= true;
        if (t->right) t->right->rev ^= true;
        t->rev = false;
    }
}
```

Все операции (split, merge) начинаются с `push(t)`.

**Переворот отрезка \[l, r\]:**

```cpp
void reverse(Node*& t, int l, int r) {
    Node *A, *B, *C;
    split(t, l, A, B);         // A = [0..l-1], B = [l..n-1]
    split(B, r - l + 1, B, C); // B = [l..r], C = [r+1..n-1]
    B->rev ^= true;            // помечаем
    t = merge(merge(A, B), C);
}
```

### 13.6 Агрегатные функции на отрезке

Можно хранить в узле дополнительные значения:

```cpp
struct Node {
    int value, priority, cnt;
    bool rev;
    long long sum;   // сумма поддерева
    int mn;          // минимум поддерева
    Node *left, *right;
};

void update(Node* t) {
    if (!t) return;
    t->cnt = 1 + getSize(t->left) + getSize(t->right);
    t->sum = t->value + getSum(t->left) + getSum(t->right);
    t->mn = min({t->value, getMin(t->left), getMin(t->right)});
}
```

**Сумма на отрезке [l, r]:**

```cpp
long long rangeSum(Node*& t, int l, int r) {
    Node *A, *B, *C;
    split(t, l, A, B);
    split(B, r - l + 1, B, C);
    long long ans = B ? B->sum : 0;
    t = merge(merge(A, B), C);
    return ans;
}
```

## Глава 14. Анализ и практика

### 14.1 Сводка сложностей

| Операция | Обычный Treap | Implicit Key Treap |
|----------|--------------|-------------------|
| Поиск | O(log n) ожид. | O(log n) ожид. |
| Вставка | O(log n) ожид. | O(log n) ожид. |
| Удаление | O(log n) ожид. | O(log n) ожид. |
| Split | O(log n) ожид. | O(log n) ожид. |
| Merge | O(log n) ожид. | O(log n) ожид. |
| Переворот отрезка | — | O(log n) ожид. |
| Сумма на отрезке | — | O(log n) ожид. |
| Вставка в позицию | — | O(log n) ожид. |

### 14.2 Сравнение трёх деревьев

| Критерий | AVL | Красно-чёрное | Treap |
|----------|-----|---------------|-------|
| Баланс | Строгий (±1) | Мягкий (×2) | Вероятностный |
| Высота | ≤ 1.44·log n | ≤ 2·log(n+1) | ≈ 3·log n ожид. |
| Гарантия | Worst-case | Worst-case | **Expected** |
| Поиск | ⭐ Лучший | Хороший | Хороший |
| Модификация | Хорошо | ⭐ Меньше поворотов | Хорошо |
| Split/Merge | Сложно | Сложно | ⭐ **Нативно** |
| Неявный ключ | Нет | Нет | ⭐ **Да** |
| Код | ~80 строк | ~150 строк | ⭐ **~40 строк** |
| Применение | БД (чтение) | STL, ОС | Контесты, массивы |

### 14.3 Преимущества treap

1. **Простота кода** — Split и Merge по ~10 строк каждый, всё остальное через них
2. **Универсальность** — Split/Merge позволяют делать вещи, недоступные AVL и КЧ-деревьям (переворот отрезка, вставка в середину массива)
3. **Неявный ключ** — мощнейшая техника для работы с последовательностями
4. **Персистентность** — легко сделать персистентным (сохранять все версии)

### 14.4 Недостатки treap

1. **Нет гарантии в худшем случае** — злонамеренный противник может подобрать приоритеты (но на практике это невозможно, если приоритеты случайны)
2. **Кэш-промахи** — узлы разбросаны по памяти (как и у всех деревьев на указателях)
3. **Рекурсия** — глубокая рекурсия может вызвать переполнение стека (можно переписать итеративно)
4. **Недетерминированность** — разные запуски дают разные деревья (для отладки можно фиксировать seed)

### 14.5 Полная реализация обычного Treap на C++

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

struct Node {
    int key, priority;
    Node *left, *right;
    Node(int k) : key(k), priority(rand()),
                   left(nullptr), right(nullptr) {}
};

void split(Node* t, int key, Node*& L, Node*& R) {
    if (!t) { L = R = nullptr; return; }
    if (t->key < key) {
        split(t->right, key, t->right, R);
        L = t;
    } else {
        split(t->left, key, L, t->left);
        R = t;
    }
}

Node* merge(Node* L, Node* R) {
    if (!L) return R;
    if (!R) return L;
    if (L->priority > R->priority) {
        L->right = merge(L->right, R);
        return L;
    } else {
        R->left = merge(L, R->left);
        return R;
    }
}

bool search(Node* t, int key) {
    if (!t) return false;
    if (key == t->key) return true;
    return key < t->key ? search(t->left, key) : search(t->right, key);
}

void insert(Node*& t, int key) {
    if (search(t, key)) return;
    Node *L, *R;
    split(t, key, L, R);
    t = merge(merge(L, new Node(key)), R);
}

void erase(Node*& t, int key) {
    if (!t) return;
    if (t->key == key) {
        Node* temp = t;
        t = merge(t->left, t->right);
        delete temp;
    } else if (key < t->key) {
        erase(t->left, key);
    } else {
        erase(t->right, key);
    }
}

void print(Node* t, int indent = 0) {
    if (!t) return;
    print(t->right, indent + 4);
    for (int i = 0; i < indent; i++) cout << ' ';
    cout << t->key << " (p=" << t->priority << ")\n";
    print(t->left, indent + 4);
}

int main() {
    srand(time(0));
    Node* root = nullptr;

    for (int i = 1; i <= 15; i++)
        insert(root, i);

    cout << "After inserting 1..15:\n";
    print(root);

    erase(root, 5);
    erase(root, 10);

    cout << "\nAfter removing 5, 10:\n";
    print(root);

    return 0;
}
```

### 14.6 Полная реализация Implicit Key Treap на C++

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
#include <algorithm>
using namespace std;

struct Node {
    int value, priority, cnt;
    bool rev;
    Node *left, *right;
    Node(int v) : value(v), priority(rand()), cnt(1),
                   rev(false), left(nullptr), right(nullptr) {}
};

int getSize(Node* t) { return t ? t->cnt : 0; }

void update(Node* t) {
    if (t) t->cnt = 1 + getSize(t->left) + getSize(t->right);
}

void push(Node* t) {
    if (t && t->rev) {
        swap(t->left, t->right);
        if (t->left) t->left->rev ^= true;
        if (t->right) t->right->rev ^= true;
        t->rev = false;
    }
}

void split(Node* t, int k, Node*& L, Node*& R) {
    if (!t) { L = R = nullptr; return; }
    push(t);
    int leftSize = getSize(t->left);
    if (leftSize >= k) {
        split(t->left, k, L, t->left);
        R = t;
    } else {
        split(t->right, k - leftSize - 1, t->right, R);
        L = t;
    }
    update(t);
}

Node* merge(Node* L, Node* R) {
    if (!L) return R;
    if (!R) return L;
    push(L); push(R);
    if (L->priority > R->priority) {
        L->right = merge(L->right, R);
        update(L);
        return L;
    } else {
        R->left = merge(L, R->left);
        update(R);
        return R;
    }
}

void insertAt(Node*& t, int pos, int val) {
    Node *L, *R;
    split(t, pos, L, R);
    t = merge(merge(L, new Node(val)), R);
}

void eraseAt(Node*& t, int pos) {
    Node *L, *mid, *R;
    split(t, pos, L, mid);
    split(mid, 1, mid, R);
    delete mid;
    t = merge(L, R);
}

void reverse(Node*& t, int l, int r) {
    Node *A, *B, *C;
    split(t, l, A, B);
    split(B, r - l + 1, B, C);
    if (B) B->rev ^= true;
    t = merge(merge(A, B), C);
}

void printArray(Node* t) {
    if (!t) return;
    push(t);
    printArray(t->left);
    cout << t->value << " ";
    printArray(t->right);
}

int main() {
    srand(time(0));
    Node* root = nullptr;

    // Создаём массив [1, 2, 3, 4, 5, 6, 7, 8]
    for (int i = 1; i <= 8; i++)
        insertAt(root, i - 1, i);

    cout << "Initial: ";
    printArray(root); cout << endl;

    // Переворачиваем [2, 5] (0-indexed)
    reverse(root, 2, 5);
    cout << "After reverse [2..5]: ";
    printArray(root); cout << endl;

    // Вставляем 99 на позицию 3
    insertAt(root, 3, 99);
    cout << "After insert 99 at pos 3: ";
    printArray(root); cout << endl;

    // Удаляем позицию 0
    eraseAt(root, 0);
    cout << "After erase at pos 0: ";
    printArray(root); cout << endl;

    return 0;
}
```
